# 视觉与运行验收

编译、运行、视觉是三项不同结论。用户已确认的资产版本可复用，不为每个页面重复申请确认。

新页面、参考还原或明显布局变更：工具允许时打开真实产物，检查首屏层级、边界、密度、内容截断/溢出，以及本次新增的主要交互。参考还原尽量使用同一视口对照；自然语言页面检查主要任务是否突出、辅助内容是否挤占主区。布局涉及折叠时再查窄桌面；启用深色时查深色可读性。不要每次小改重复全套检查。

资产维护：对骨架收展、页签、长标题、输入/IME/附件/发送停止、浅深主题与桌面宽度建立一次基线；项目集成重点查配置、业务装配与溢出。表格页码需控制真实切片/请求，不能只是装饰。

浏览器工具不可用或被安全策略阻止：不换路径绕过，不声称通过；保留编译产物，列明未测项。用户视觉确认可记录为人工评审，但不能改写成自动化交互或多尺寸实测。

问题集中修复，沿用主 skill 验证轮次上限；性能和美观提升需要同任务对比证据，没有实测就不作提升声明。
