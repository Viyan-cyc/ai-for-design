# 图表源码接入说明

本目录是 Vue 3 + JavaScript + ECharts 源码。离线预览通过不代表已经接入目标业务工程；接入时核对版本、路由、构建配置和宿主样式。

## 依赖与入口

- 直接 ECharts 页面需要 vue、echarts；使用 EP 控件时需要 element-plus@2.13.5 和相应样式，图标需要 @element-plus/icons-vue。
- 当前 main.js 安装 EP 并加载浅深主题。以实际导入为准安装依赖；使用 dayjs、vue-echarts、vue-i18n 时再安装对应包，不把 vue-echarts 作为直接 ECharts 页面的必要条件。
- Less 文件需要目标工程配置 less。使用与预览运行库兼容的依赖版本；升级版本后重新验证。
- main.js 是接入参考，离线预览不执行它。已有项目应在其入口装配主题和按需国际化，不能整体覆盖原入口。

## 搬入业务工程

1. 搬入页面、服务层、实际使用的辅助模块和素材，并配置页面路由。
2. 图表专用样式在 src/assets/charts/（如使用），由页面显式 import，必须随页面一起交付。容器局部变量的作用域应覆盖图表实例。
3. EP 外围控件需要对应 themes/ 桥接；图表颜色与参数遵循选定图表规范，不替换成近似 EP token。
4. API 保留 Promise 接口，mock 只由 API 模块消费；对接真实后端时替换服务实现。
5. 核对容器高度、ResizeObserver、实例销毁和主题变化后的 option 更新。Canvas 配色需解析为实际色值，不直接传 CSS var()。
6. 在目标工程实际安装、构建并运行页面，检查任务要求的交互与图片导出。
