2. 随附Grid页面：`python -m http.server 4191 --bind 127.0.0.1 --directory <skill>/assets/runtime/debug`，打开本机4191。页面内改参数、实际导出、关闭重开后导入；格式错误应保持旧状态。
3. Grid工具绑定登记的隔离基线，不能导入本skill新组件ZIP。它导出的样例要求相同工具版本，不声称preset自包含新的组件实现。
4. 其他组件：先按其现有宿主验证，或在独立副本增加明确适配器。控件JSON不是脚本执行入口，不直接执行未知包。
5. 记录参数语义、单位、状态、真实数据/演示数据。业务空数据隐藏等策略按用户选择，不静默演示回退。
