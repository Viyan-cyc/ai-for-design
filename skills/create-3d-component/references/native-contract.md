# 组件库原生交付规范

默认初始化提供原生TypeScript对象模板；旧mjs模板通过--profile legacy保留。native-host提供普通Mesh静态高亮及可选脉冲示范，地图自动模板尚未提供。不能仅凭预览成功宣称任意组件可原样入库，仍需对实际目标库验证。

## 源码和依赖
组件以TypeScript导出公共类或工厂函数，参数和返回类型明确。组件根src内相对导入保持内部闭合；不导入example、工作机路径或新建渲染器来替代借用宿主。Three等基础库使用目标库允许的peer dependency；地图依赖仅适用地图组件。组件代码不携带另一份vendor/three。不采用生产包自己的公共入口自导入以避免循环依赖；内部库类型引用必须在目标目录副本验证。

目标库当前以ES2022/ESNext/bundler检查，开启noUnusedLocals/noUnusedParameters；以分类入口输出ESM、CJS及声明。组件src/<分类>/<组件>/的导入必须在真实目标目录结构中检查，不能只在独立Demo编译。

## 分类与宿主
分类决定对外import路径，宿主决定怎样创建和调度，两者不是同一个字段。

|宿主形态|公开接口与所有权|验证重点|
|---|---|---|
|三维对象|导出Object3D子类或返回Object3D的工厂；参数初始化，提供适用的更新及dispose|两份实例独立、挂载/移除、释放自身几何材质，不销毁共享资源|
|附加效果|明确传入宿主和数据；启停/参数更新/释放；动画交给宿主调度|关闭后宿主恢复、重复释放、无私自持续RAF、不硬编码演示业务|
|地图图层|对当前MapRuntime公开接口适配，记录地理坐标/投影与图层所有权|重复添加/移除、缩放/resize/主题和资源释放；非Object3D接口不强行转换|
|工具或材质|按实际导出类型描述，无须伪造挂载接口|函数输入输出/材质资源所有权与依赖|

普通组件选项按需兼容库中的name/visible/userData；不要给不适用的函数强加这些字段。参数更新方法与逐帧update(delta)区分，不能用同名不同语义掩盖冲突。

## 参数与资料
执行代码提供默认值、校验及归一化逻辑。面板定义只描述标签、单位和控件，不另存独立默认值。设计说明解释效果与可调范围；工程说明只写接入、依赖、资源、实际限制和最小用例。需要项目数据的字段不能伪装成通用默认数据。

## 接纳与同步
开发审核后，先在当前组件库真实副本复制源码并注册分类导出，执行该库类型检查、构建和实际使用验证。源码保持原字节；需要修改核心代码说明候选尚未达到接纳标准。依赖冲突/重名/目标变更停止，不覆盖。
库接纳不等于generate-3d-scene完整接入。包/文档同步与创建/更新/销毁及适用保存恢复的适配分别验证。导出、设计确认、工程通过、发布分别记录，不由任何一项自动推导其余状态。
