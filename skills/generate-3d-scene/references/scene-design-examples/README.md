# 按领域选择场景设计

普通生成读取 common.md 和命中的一个领域文件。只检查模型包时不读本目录；局部修改不重新加载全部领域。没有参考图也可按自然语言生成，不追问用户挑选风格。

| 自然语言需求 | 领域文件 | 默认表达 |
|---|---|---|
| 仓库、物流中心、立体库 | warehouse.md | 明亮工业；深色按需求 |
| 工厂、通信电子制造、天线/计算/无线产品车间 | factory.md | 明亮工业 |
| 港口、泊位、集装箱堆场 | port.md | 浅色沙盘 |
| 机房、数据中心 | data-center.md | 明亮工业 |
| 园区、会展建筑、地图 | campus.md | 浅色沙盘 |
| 无线网络、基站、覆盖、干扰 | wireless.md | 明亮或浅色沙盘 |

无线网络是业务叠加层；涉及园区底景时再补读 campus.md。无线产品制造归 factory.md，不要误生成通信覆盖地图。其他多领域需求只补读实际涉及的文件。

领域配方提供可选模块，不是每次全部生成。用户明确需求优先；没有明确要求的动画、双视口、业务看板、主题切换不自动添加。构建通过直接交付，不新增浏览器审核和审美重试。
