# 按领域选择场景设计

普通生成按需读取[共同约定](common.md)与命中的领域文件；局部修改只读相关内容，模型包检查不加载设计目录。自然语言即可开始，具体风格遵循用户需求与已有设计。

| 需求 | 阅读入口 | 建议范围 |
|---|---|---|
| 仓库、物流中心、立体库 | [仓储](warehouse.md) | 物流布局与工业表达建议 |
| 工厂、通信电子制造 | [工厂](factory.md) | 工序与线边物流建议 |
| 港口、泊位、箱区 | [港口](port.md) | 海陆关系及示意港口建议 |
| 机房、数据中心 | [机房](data-center.md) | 机柜与配套设施建议 |
| 示意园区、会展建筑群 | [园区](campus.md) | 示意布局 |
| 真实地理底图、城市地图 | [地图接入](../map.md) | 真实数据与地图服务；不是示意园区配方 |
| 无线网络、基站、覆盖 | [无线业务](wireless.md) | 业务叠加层 |
| 室内房间 | [室内建议](interior.md) | 家具、通行与去顶表达；具体尺寸按项目 |

无线网络是业务叠加层；示意园区底景补读[campus.md](campus.md)，真实地理底景读[地图接入说明](../map.md)。无线产品制造归[factory.md](factory.md)，其他多领域需求只补读实际涉及的文件。

领域配方提供可选模块，不是每次全部生成。用户明确需求优先；没有明确要求的动画、双视口、业务看板、主题切换不自动添加。构建与验收边界见 [主入口](../../SKILL.md)。

真实地图的设计来源、主题预设与项目参数边界见[地理地图设计指南](geographic-map.md)；接入及服务配置仍见[地图说明](../map.md)。
