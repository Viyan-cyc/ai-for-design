# 场景设计示例 · 首批打样

这里提供首次生成的设计起点，不是行业工程标准，也不是必须照抄的场景模板。当前仅供评审，尚未加入默认生成流程。

领域决定空间关系与常见对象，风格决定配色、材质、灯光和表达方式。不要把“仓库”永久绑定一种配色，把“港口”永久绑定一种视角。用户提供的风格、参考图、品牌和业务布局优先。

| 示例 | 默认表达 | 主要设计问题 |
|---|---|---|
| warehouse.md | 冷灰工业、清晰鸟瞰、橙蓝识别色 | 屋顶遮挡、密集阵列、室内层次 |
| port.md | 日间海港、克制写实、海陆分区 | 大尺度取景、岸线关系、重复资产预算 |

使用方式：按需只读对应一份。把设计决策直接落实到场景数据和代码，不额外生成设计报告、不索要逐项确认、不增加截图审核或审美重试。构建规则沿用主 skill。

共享原则：
- 匹配的用户模型和库模型优先使用；库模型直接下载注入，不新增模型检查。不要为追求配色统一擅自覆盖模型全部材质。
- 用布局、地面、照明、标识协调不同来源资产。无法匹配的对象才按原有规则几何降级。
- 按最终视距分配细节；独立编排对象保留独立节点，重复零件的合批不能破坏所需编辑粒度。
- 配色表是建议的设计色，不直接等于渲染后像素颜色；不固定曝光来保证颜色相同。
- 所有尺寸为示意布局参考，不替代消防、港务、道路或生产工艺规范。
