# 港口示例：清晰的海陆物流关系

## 设计目标

第一眼看懂海面、岸线、泊位、岸桥、堆场和陆侧道路的关系。默认日间、低饱和海港风格，主体结构清楚，色彩集中在集装箱和机械设备；不默认加入夜景霓虹和大面积发光线。

## 一份具体的场景草案

示意展示范围宽约 800 米、深约 500 米。岸线沿 X 轴，海域在 -Z 侧，陆域在 +Z 侧。世界原点可放在展示岸线中段，岸线几何与业务区域共同决定相机目标。

- 船舶长轴沿岸线摆放，不横穿岸线；岸桥沿泊位排列，悬臂朝海侧，覆盖船舶作业方向。
- 集装箱堆场在岸桥后方，按箱区成组排列；箱区之间保留连续运输道路与横向联络通道。
- 陆侧布置闸口、集卡等待区、仓储和辅助设施；道路连接实际装卸节点，不画成无出口装饰线。
- 重点展示一个作业泊位及相邻箱区，其余区域降低细节，避免每处都成为视觉焦点。
- 宏大感来自船舶、岸桥、集卡与集装箱的尺度对比及阵列纵深，不靠雾遮住大半场景。

具体泊位间距、作业净空与道路尺寸按需求或项目数据确定；这里不提供生产工程合规结论。堆高不超过用户指定层数，箱体与车辆不得互相穿插。

## 视觉方案

| 部分 | 建议 |
|---|---|
| 海面 | 低饱和蓝青 #397C92；轻微明暗变化，不做镜面反射海洋 |
| 陆面 | 混凝土灰 #AEB8BF；道路深灰 #4D5965 |
| 大型设备 | 蓝灰或项目品牌色，结构轮廓与背景保持区别 |
| 集装箱 | 蓝 #376B92、砖红 #A95342、绿 #587665、浅灰 #C5CDD2，按箱区有限循环 |
| 安全标识 | 少量暖黄，用于边界与作业重点，不覆盖全场 |

保留库模型原有材质，不强制把所有船舶和设备重涂成同一种颜色。水面优先简单材质/轻量纹理，复杂反射与动态海浪只在用户明确需要时增加。

## 相机与构图

默认从海侧斜俯视陆域，同时看到船舶侧面、岸桥轮廓及后方箱区。岸线在画面中形成斜向引导线，不让整条岸线机械地横切画面正中。

总览以完整业务区域包围盒取景，包含船舶与岸桥最高点；按屏幕比例留边，避免裁掉吊臂。背景海面等装饰性无限平面不参与取景包围盒，避免把主体缩得过小。

透视相机用于规模与纵深；用户要规划图式总览时可用正交。无论哪种，都按场景尺度设置 near/far 和控制范围。不要照搬室内小场景的 80 米最大观察距离。

## 灯光与环境

使用单一日光方向形成设备明暗面，环境补光保持阴影可读。海面与天空使用同一冷色环境，箱体保留适度暖色对比。

雾是可选项，只作用于远端背景，不能让主要箱区失去可读性。大场景阴影优先覆盖重点作业区，不默认让所有远景集装箱都投射高精度动态阴影；也不增加数十个投影灯。

## 首版细节取舍

必须读得出来：岸线、船岸关系、岸桥作业方向、成组箱区、运输道路和车辆比例。
按需要补充：箱体波纹、船舱轮廓、岸边护栏、闸口、编号、少量集卡。
远景可省略：钢缆完整物理结构、每箱锁扣、车辆底盘、逐盏点光源、每片海浪几何。

阵列数量先估算整体资产成本；远处少做不可见小零件，不牺牲用户需要的对象独立选择、移动和材质编辑。不能把“可以实例化”直接当成完整编辑能力已支持。

避免：船舶漂在陆地；岸桥背对海面；箱区没有运输道路；海面占满画面而主体过小；箱体颜色完全随机；全场同等细节导致卡顿。

## 可直接用来试生成的需求

“生成一个集装箱港口总览，展示船舶靠泊、岸桥装卸、箱区与集卡运输道路。日间工业风，布局有秩序，规模宏大，主体清晰，支持编辑，不需要复杂海浪效果。”

检索命中合适的船舶、岸桥、集卡或集装箱时直接下载注入；未匹配对象再按现有规则降级。首版完成后统一构建交付，不追加视觉门禁。
