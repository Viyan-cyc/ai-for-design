# 共享设计规范

自然语言足够开始设计，不要求用户提供参考图。用户明确需求 > 当前工程已有设计 > 领域默认 > 本页默认。未知参数合理补全，但不把示意设计冒充生产工程规范。

## 风格选择

风格由适用领域指南给出建议，用户明确需求与工程现有设计优先。角色配色与材质意图按领域维护，真实地图的技术入口见[地图接入说明](../map.md)。

领域配色按来源和确认状态选用，保留模型合理原材质。品牌色由用户需求覆盖；深浅主题切换按实际需求启用。

工业布局仿真是一种组织方式：强调阵列、工序和物流，不是第四种色板。可以与任一风格组合；也不意味着需要自动实现仿真引擎。

## 构图、质量与实现边界


- 首次写场景前明确：主要功能区及连接关系、主体与背景、观察方向、主色与强调色、细节重点。直接落实到代码与场景数据，不额外写报告或让用户逐项确认。
- 丰富度来自主体、辅助设施、地面标识三个层次。通道与作业空间保持连通，不能靠随意增加物体填满空地。按实际资产占地及旋转后范围安排间距；不假设库里所有模型尺寸一致。
- 取景围绕业务范围，相机与控制器目标一致；依据画布宽高比和最高物体计算机位及留边。near/far、控制距离、光源位置与阴影覆盖随实际范围设置。
- 重要内容不能被屋顶、前墙或楼板挡住。总览需要时采用去顶/剖切/分层展示；用户要求完整建筑时保留建筑，并选择满足需求的视角。不要不加说明改变业务楼层关系。
- 使用有限配色与材质差异体现结构；阴影用于表达接触和体积。保留库模型合理的原始材质，不为统一配色强行重涂所有模型。浅色不等于曝光过高，深色不等于设备全黑。
- 按最终视距分配细节：近处主体轮廓、分件与少量倒角优先；远景省略螺丝、锁扣和不可见内部结构。灯具外观不等于每盏都要创建光源。重复对象保留用户需要的独立编辑能力。
- 景深、反射、辉光是可选表达，不默认引入昂贵后处理；不照搬模糊、大片发光线和高反射地面。精密设备优先匹配模型，几何降级保留轮廓与功能特征，不承诺等同精模。
- 3D 风格与业务 UI 分开：仅用户要求数据大屏/业务操作时添加相应面板、图表、状态标记。不要额外添加品牌、水印、字幕和聊天入口。
- 构建与交付按[场景工作流](../scene-workflow.md)执行。本目录是设计指导，不新增生成门禁；实际视觉效果由用户确认。
- 文中的布局尺寸是展示示例，不是消防、生产工艺或港务合规标准。未知领域按上述原则设计，不硬套现有示例。

## 自然语言落实方法

从需求提取：功能区、对象类别、数量、连接关系、视觉要求、交互功能。先安排区域与主通道，再按资产实际占地展开设备，最后补辅助设施和标识。

明确数量要保留；需求未给数量时，以空间容量和视觉清晰度选择，不复制示例全部数量。无法同时满足尺寸、数量和通道时说明冲突，不静默改量或让对象重叠。

渲染参数由场景范围和引擎能力决定。不要把旧项目的缩放倍率、相机距离、灯光强度当通用常量。用户明确要求的功能不能静默忽略；缺少支持时说明具体限制。


## 配置与能力边界

本目录是未确认的设计建议，不是设计师原始方案或运行预设。领域规则与风格分开；布局数量、地点和绝对机位属于项目，取景规则可以复用。项目明确需求优先，其次保留当前设计，再选领域建议；预设更新不自动改已有项目。

参数采用四类来源：模板默认引用实际预设；场景计算引用算法及输入；项目提供引用需求／配置；启用功能后提供注明条件。每个采用的参数记录单位、现有字段／转换、来源版本、应用与重置范围、实现支持和验证状态。未知映射标待确认，不加入运行默认。当前各领域尚无已确认独立参数预设，文中色彩是意图，运行值以项目配置为准。

### 条件内容

使用光照时说明主补光、环境、阴影和曝光实际含义，地图图层颜色不等于Three材质；画质与性能沿用现有配置。标签／卡片填写屏幕或世界尺寸、缩放显隐、信息优先级及重叠策略；业务数据填写单位、图例、真实／演示、空值异常及状态色，并用文字或符号辅助颜色识别。只启用实际需要且支持的功能。

可编辑交付按[编辑与回传说明](../scene-workflow.md)核对选择、锁定、显隐、撤销和保存／重载。临时选中效果不写永久外观，预设只覆盖声明字段。多主题注明用户覆盖保留与清除规则；动画注明触发、暂停、打断和释放及按需渲染更新。高级候选能力不因领域名称自动启用。

### 响应视口与资源状态

具体方案说明窗口宽高比变化时如何调整取景、标签／卡片和操作布局，是否保留当前观察状态，以及窄窗口收起／滚动方式。已有通用实现可引用具体路径、版本及适用条件；未核对行为写待确认，不宣称自动支持。

对模型、贴图及实际使用的地图资源，说明加载中、部分失败、不可用时的提示、占位／保留内容、仍可用操作和恢复方式。可降级与必须停止的情况分别说明；地图资源边界见[地图接入](../map.md)。未定义的策略标待确认，不能静默将缺失内容视为完整场景。
