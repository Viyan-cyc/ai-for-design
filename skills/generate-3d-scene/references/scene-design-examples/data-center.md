# 机房布局指南
建议采用明亮工业表达；深色设施展示按用户需求选用。

- 机柜按行/组布置，预留纵向通道和横向联络空间；制冷、配电、运维区与机柜区建立清楚关系。真实冷热通道、供电和消防设计以用户资料为准。
- 机柜宽深高来自模型尺寸；机柜正面朝向按行统一，成对通道根据需求相向或背向，不只追求整齐外观。
- 主体是机柜阵列，辅助是配电/制冷/线槽，地面网格和区域编号为第三层。线槽不盖住全部机柜，线缆无需每根精细建模。
- 总览去顶并弱化前墙，保留少量建筑结构作尺度参照。深色机柜与浅灰地面形成对比；前门、侧板、设备面板有粗糙度和明度区别。
- 指示灯少量点缀，不把所有机柜变成发光灯箱。不默认生成热力图、实时指标或运维大屏。

可选需求示例（仅表达一个项目）：试生成：“生成一个四组双排机柜的机房，带配电、制冷和运维区，浅灰环境、深色机柜，布局清楚、细节精致，支持编辑。”


## 来源与使用边界

本页为既有生成示例整理的领域建议，尚非设计师确认的参数预设。来源版本与逐段迁移记录由维护仓库记录；项目采用时须记录实际指南版本及设计确认。布局、配色与交互按需求选用，具体参数来源、响应视口、加载状态、实现支持和验收继承[共同约定](common.md#配置与能力边界)。本页不声称新增运行能力；实际参数引用项目配置，未核对的实现／参数标待确认。

配色参考：灰白主体、浅灰环境、少量识别色，金属半哑光，材质差异表达结构。深色展示可用深灰蓝环境、灰白设备和少量业务强调色，保持暗部可读；这些是建议，非确认预设。
