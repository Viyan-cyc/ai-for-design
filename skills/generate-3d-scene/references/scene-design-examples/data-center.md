# 机房布局示例
默认风格：明亮精致工业；用户要求深色设施展示时使用深色工程展示。

- 机柜按行/组布置，预留纵向通道和横向联络空间；制冷、配电、运维区与机柜区建立清楚关系。真实冷热通道、供电和消防设计以用户资料为准。
- 机柜宽深高来自模型尺寸；机柜正面朝向按行统一，成对通道根据需求相向或背向，不只追求整齐外观。
- 主体是机柜阵列，辅助是配电/制冷/线槽，地面网格和区域编号为第三层。线槽不盖住全部机柜，线缆无需每根精细建模。
- 总览去顶并弱化前墙，保留少量建筑结构作尺度参照。深色机柜与浅灰地面形成对比；前门、侧板、设备面板有粗糙度和明度区别。
- 指示灯少量点缀，不把所有机柜变成发光灯箱。不默认生成热力图、实时指标或运维大屏。

试生成：“生成一个四组双排机柜的机房，带配电、制冷和运维区，浅灰环境、深色机柜，布局清楚、细节精致，支持编辑。”
