# 仓库示例：有秩序的工业物流鸟瞰

本指南提供仓储布局与明亮工业表达建议，未经设计师确认。已选风格或用户要求优先。

## 设计目标

第一眼看懂存储、分拣、装卸与物流动线；第二眼看到货架结构、托盘、车辆和工位。主通道与区域边界清楚。日间冷灰、深色、品牌展示或写实风格按项目选择。

## 一份具体的场景草案

可选布局示例（非默认、非合规标准）：地面中心为原点，+Y向上；装卸门在+Z侧，主通道沿Z贯穿，左侧存储、右侧暂存／大件区，靠门为装卸分拣，打包办公沿边布置。实际长宽高由项目提供。

- 左侧按真实货架尺寸排布多组平行货架；组间留横向联络通道，避免从门口到深处只有一条路。
- 右侧按需求放大件或集装箱；未提集装箱时，不为丰富画面擅自加入大型箱场。
- 中间保留连续主通道，车辆不得横堵通道；车辆位置体现转运关系，而非平均散布。
- 装卸月台与门洞对齐，分拣传送带连接暂存和打包区。
- 远处保持阵列节奏，近处选择少量托盘、护栏、叉车、工位补足识别细节。

数量由区域面积、资产包围盒和通道空间计算，不先承诺“几十排”再硬塞。货架及集装箱高度不得穿屋顶。间距采用投影到布局平面的占地范围，转向后重新计算，不能仅使用旋转前宽深。

## 视觉方案

以下为未确认的角色配色建议，不作为固定运行预设：

| 部分 | 建议 |
|---|---|
| 基础色 | 地面浅灰；墙面灰白；钢结构深灰 |
| 识别色 | 货架橙、梁蓝；标线黄 |
| 货物 | 木托盘与纸箱使用少量相近棕色变体，避免彩虹随机色 |
| 材质 | 地面低反射、钢结构半哑光、纸箱高粗糙；玻璃只在需要的部位使用 |
| 辅助标识 | 区域编号、少量通道箭头与安全标线；避免每个物体都悬浮文字 |

模型已有正确材质时保留，色彩通过地面、标线与环境协调。倒角优先给近处主体的轮廓，不给所有货物增加细分。

## 相机与可见性

总览从可同时看清门口、主通道和纵深的方向斜俯视，按业务包围盒及画布比例计算机位和留边；相机target与OrbitControls target一致。

仓库外壳不能挡住主内容：总览默认采用去顶/剖切表达，保留必要的后墙和部分梁架。用户要求完整建筑外观时另按该需求表达，不能静默删屋顶。梁架不要铺满屏幕遮挡货架。

相机距离、near/far、控制距离和阴影覆盖随实际场景范围调整，不沿用小场景的固定距离。完整取景应同时考虑画布宽高比、水平和垂直视野。

## 灯光

使用柔和环境补光与一个主要方向光建立体积感。顶部灯带表现物流节奏，但不要给每盏灯都建立投影灯光；灯带可用自发光材质。重点保证货架内侧不是死黑、地面不过曝、货物之间能分辨。

主光阴影覆盖实际展示区域；阴影清晰度结合覆盖范围与现有画质档位调整，先保证接触关系和层次，后处理按实际需求使用。

## 首版细节取舍

必须读得出来：功能分区、连续通道、整齐阵列、装卸关系、车辆尺度。
按需要补充：货架层板、托盘、护栏、包装台、区域标识。
远景可省略：螺丝、纸箱微纹理、每个灯具独立光源、被遮挡的内部零件。

避免：只摆货架不做区域关系；为“丰富”塞满所有空地；屋顶遮住室内；随机摆放叉车；相同纸箱复制到毫无层次。

## 可直接用来试生成的需求

可选需求示例（仅表达一个项目）：“生成一个大型仓库物流总览，冷灰工业风。包含高位货架、分拣打包、暂存和装卸区。主通道清楚，货物丰富整齐，能看到叉车转运；采用可看清室内的鸟瞰表达，支持编辑。”

生成、构建与交付遵循[场景工作流](../scene-workflow.md)，示例不增加单独审批步骤。


## 可选配方：大中型智能仓储物流中心

按用户需求组合高架货架、地面暂存、装卸月台、分拣包装、设备工位、安全设施六类区域。装卸→暂存→存储/拣选→包装→出库连接成可读动线，辅机沿对应流程布置。

- 高架区：先确定每组货架宽深高与层列，再确定货架长轴、组的排列方向和通道方向。“沿 X 排列”不足以同时表达三者。货架组间及端部留出连接主通道的空间。
- 地面区：区分独立托盘、承载货物的托盘和堆叠空托盘。同一承载关系不要重复生成一套独立托盘阵列。数量语义不明且影响可行性时只澄清关键问题。
- 分拣区：直线、转弯、皮带/滚筒输送段与封箱、称重、缠绕、码垛设备形成连接，不把不同设备各摆一排。
- 月台：车辆与门洞/泊位对齐，道路保留通行；充电设施放在通道边安全可达的区域，不堵主通道。
- 辅助对象：工作台、办公、机械臂、提升平台、消防、安防等按实际需求加入。

明确大量实例的总量、承载和堆叠关系，依据资产尺寸计算容量。叉车通道按项目要求与实际作业空间确定，示例不提供通用净宽标准。

大量重复资产需要考虑总体几何、绘制与编辑成本；不能因单模型合格就默认上万实例不卡，也不能擅自减少明确数量。保留用户要求的独立编排与材质编辑粒度。

深色方案可配浅灰地面和橙蓝货架，重点保持内侧可读，灯光参数按实际渲染能力配置。双主题、AGV自主行驶、状态／运单／库龄卡片按需求启用并核对支持。
