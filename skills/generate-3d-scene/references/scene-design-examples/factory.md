# 工厂布局示例
默认风格：明亮精致工业；强调工艺仿真时可选工业布局仿真。

- 先组织收料→加工/装配→检测→包装→出料的业务关系；具体流程由用户需求决定，不擅自补成真实生产工艺。
- 产线按模块平行或 U 形布置，输送段连接相邻工位，人员/物料通道保持连通。辅助电柜、工位台和暂存区靠对应工序，不随机散布。
- 根据机器实际占地安排节拍工位及间距，不把同一机器简单复制替代不同工序。近景挑一条产线细化，远景保留一致轮廓与阵列节奏。
- 去顶鸟瞰优先看清设备上表面及物流方向；柱网、钢梁不遮住核心工序。设备白壳以深色观察窗、接缝、工作区形成层次。
- 有需求才添加产量/告警标注；不默认复刻图 2 的品牌、指标和侧栏。

试生成：“生成一个电子装配工厂总览，多条整齐产线，包含检测、包装、暂存区，明亮精致工业风，能看清物料动线，支持编辑。”
