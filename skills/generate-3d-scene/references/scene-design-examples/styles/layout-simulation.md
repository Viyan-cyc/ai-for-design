# 工业布局仿真
参考：用户图 3 多层密集仓储、图 4 自动化仓储。目标是先读懂物流或工艺，再看设备细节。

- 基础采用中性灰地面、浅灰结构；蓝/绿或品牌色按设备类别、箱区、流程分配。色彩有明确映射，不逐实例随机取色。
- 保留生产线、输送带、储位、转运车辆之间的连接，通道与操作区明确。密集阵列以模块组织，每组之间可看清边界。
- 细节集中在设备剪影、传送方向、工位结构、机械臂姿态；远景小零件减少。几何建模也需明确分件，不用单个盒子代表所有设备。
- 总览采用斜俯视；多楼层按用户目的选择剖切或层级切换。不要照搬图 3 中楼板大面积遮挡，也不要把楼层任意拉开后仍宣称真实布局。
- 光照均匀但有体积层次，地面微反射可选；不默认镜面地面。钢架不应成为遮挡主业务的视觉噪声。
- 仿真动画与数据接入仅在用户要求时实现；“仿真风格”不等于自动增加仿真引擎、实时接口或看板。
