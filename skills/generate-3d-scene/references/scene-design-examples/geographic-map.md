# 真实地理地图设计指南

## 什么时候用
需要真实城市位置、道路、水域和建筑数据时使用。示意园区布局读[园区指南](campus.md)；地图服务配置和接入读[地图说明](../map.md)。

## 希望呈现什么效果
采用已确认的上海地图设计基线中的通用深浅主题：浅色干净、低饱和，深色使用中性地面、克制绿地和蓝灰水域。保持道路、岸线、建筑与业务重点清晰。该确认只覆盖原地图设计，不自动覆盖新增标签、热力策略或编辑器行为。
建筑形状和高度以地图数据为准。白模表达实际体块，不代表精细地标模型；数据缺失时说明限制，不用虚构精模冒充真实数据。

## 怎样组合组件
- 基础地图使用[MapPresentation](../component-docs/MapPresentation.md)，通过map.theme选择light或dark。地面、道路、水域、绿地、建筑和底图文字沿用预设，不逐项手抄主题颜色。
- 地点、中心、范围、zoom、bearing和pitch按项目关注区域设置，不沿用上海样本的绝对取景。
- 没有业务数据需求时只生成底图和所需模型。散点、热力按[叠加层说明](../map-overlays.md)独立启用；扫光另按相应能力接入，不默认添加。
- 业务标签可用[ScreenLabel](../component-docs/ScreenLabel.md)，按项目定义信息、尺寸、缩放显隐及遮挡规则；底图labelSize不是业务卡片的像素尺寸。

## 哪些可以调
|内容|选择方式|
|---|---|
|主题|默认使用组件深浅预设；用户明确风格要求可覆盖|
|地图范围与取景|按业务地点和关注区域计算|
|已有工程的颜色覆盖|保留用户设置；覆盖和主题切换规则见地图说明|
|灯光、建筑和投影|使用地图组件实际支持的设置；地图光照角度不能直接当Three灯光值|
|清晰度和性能|沿用引擎画质配置，按设备与实际负载选择|
|固定城市地标|项目显式提供资产；不属于通用主题默认|

## 使用限制
默认主题适用于当前OpenMapTiles表现路径。自定义layerMapping只控制明确映射图层的颜色和显隐，不保证恢复全部主题算法；其他地图样式先核对映射。
地图资源需要联网，离线HTML不等于瓦片、字体和sprite离线。加载失败不能把空白页面当成完整地图，应提供实际可用的提示与恢复方式。
地图投影不能直接套普通透视相机焦距换算。视口变化、控件和标签布局按[共同约定](common.md)处理；主题参数一致不能代替运行或视觉验证。
编辑沿用现有编辑器的选择、锁定、撤销和保存流程，不复制原设计页面的固定城市导航或独立localStorage。新预设不自动覆盖已有工程。

设计来源与核对历史留在维护Spec；本页指导使用，不增加日常生成的审美或浏览器门禁。实际接入和生成验证遵循[主入口](../../SKILL.md)。
