# 地图与园区布局示例
默认风格：业务地图沙盘；日间浅色默认，按用户要求切换深色。

- 先确定展示边界、道路骨架、地块与业务重点，再放建筑；主路连通入口，支路到达设施，不随意穿建筑。
- 有真实地理数据时保留其坐标映射与比例；没有时使用示意布局，不宣称精确还原。大坐标按工程已有转换处理，资产坐标仍遵循统一约定。
- 重点建筑有可识别轮廓，普通背景建筑用简化体块。绿化与道路提供尺度关系，不以密集树木遮挡主体。
- 相机按业务区域而非整个背景底图取景，避免中心主体太小；不同层级场景不混用建筑级和城市级细节密度。
- 按需求加入少量位置标记或线路；无数据需求不自动生成两侧大屏。交付不依赖未授权的在线底图或外部服务。

试生成：“生成一个工业园区示意沙盘，包含生产、仓储、办公和能源区，道路连接清楚，浅色地图风格，重点突出能源设施，支持编辑。”
