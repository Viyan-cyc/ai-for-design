# BuildingTint

`import { BuildingTint } from '@a3d/a3d-components/map'`

按建筑表面每个片段的地面投影染色，同时适配原生建筑和普通Three模型；保持原几何、材质明暗与不透明度。

## 创建

```ts
new BuildingTint(map: Map$1, field: HeatField, options?: Partial<TintOptions>): BuildingTint
```

## 可调参数

以下是调节项，不等于完整构造参数；宿主与数据按示例显式提供。

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| enabled | boolean | true | 开启染色； |
| strength | number | 1 | 染色强度；0–1；0–1 |
| brightness | number | 1.5 | 建筑明度；0–2；0–2 |

## Example

```ts
import { HeatField, GridHeat, BuildingTint } from '@a3d/a3d-components/map';
// map必须来自已完成渲染适配的MapLibre；Three模型另需宿主事件接点。
const field = new HeatField();
const grid = new GridHeat(map, field);
const tint = new BuildingTint(map, field, { brightness: 1.5 });
field.setData([{ lng: 121.49517, lat: 31.24194, value: 180 }]);
grid.setVisible(false); // 关闭格子后建筑仍染色
tint.setOptions({ enabled: false }); // 恢复原建筑表现
tint.dispose(); grid.dispose(); field.dispose();
```
