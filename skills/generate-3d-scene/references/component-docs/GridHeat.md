# GridHeat

`import { GridHeat } from '@a3d/a3d-components/map'`

经纬度栅格热力。接收0–255整数值，通过共享HeatField分档着色，支持空数据、独立显示开关和实时更新。

## 创建

```ts
new GridHeat(map: Map$1, field: HeatField): GridHeat
```

## 可调参数

以下是调节项，不等于完整构造参数；宿主与数据按示例显式提供。

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| origin | object | [121.49517,31.24194] | 栅格原点，经纬度； |
| cellSizeMeters | number | 14 | 中心间距；米 |
| bins | number | 5 | 档数； |
| colorMode | string | "five" | 双色或五色插值； |
| colors | object | ["#CCFEC2","#78EE95","#FFF05C","#FFAC4D","#FF5757"] | 颜色节点； |
| sizeStart | number | ≈0.79 | 首档边长比例； |
| sizeEnd | number | ≈0.79 | 末档边长比例； |
| alphaStart | number | 1 | 首档不透明度； |
| alphaEnd | number | 1 | 末档不透明度； |
| breaks | object | [0.45,0.68,0.73,0.75] | 非均匀分界； |
| bandMode | string | "thresholds" | 均匀/非均匀分档； |
| threshold | number | 0.17 | 最低显示值/255； |
| colorBlur | number | 2.63 | 颜色平滑标准差；单元 |

## Example

```ts
import { HeatField, GridHeat } from '@a3d/a3d-components/map';
const field = new HeatField();
const grid = new GridHeat(map, field);
field.setData([{ lng: 121.49517, lat: 31.24194, value: 180 }]);
grid.setOptions({ alphaStart: 0.8, alphaEnd: 0.8 });
grid.setVisible(false); // 不影响使用同一场的建筑染色
grid.dispose();
field.dispose(); // 所有消费者释放后再释放共享场
```
