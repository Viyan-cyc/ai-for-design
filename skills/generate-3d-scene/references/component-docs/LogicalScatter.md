# LogicalScatter

`import { LogicalScatter } from '@a3d/a3d-components/map'`

逻辑坐标散点与缩放聚合。接收0–1的x/y坐标，标记保持固定CSS尺寸；不接收经纬度，也不自动投影到地图。

## 创建

```ts
new LogicalScatter(host: HTMLElement, options?: ScatterPatch, data?: readonly ScatterPoint[]): LogicalScatter
```

## 可调参数

以下是调节项，不等于完整构造参数；宿主与数据按示例显式提供。

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| pointRadius | number | 3.4 | 普通点半径；px；2–8 |
| clusterPinWidth | number | 24 | 图钉宽度；px；16–40 |
| clusterDistance | number | 28 | 聚合距离；px；12–60 |
| minClusterCount | number | 9 | 最小聚合数量；个；3–16 |
| markerStrokeWidth | number | 1.5 | 标记描边；px；0–5 |
| countFontSize | number | 16 | 数量字号；px；10–22 |
| countFontWeight | number | 500 | 数量字重；；400–900 |
| countStrokeWidth | number | 0 | 文字描边；px；0–4 |
| selectedStrokeWidth | number | 2 | 选中描边；px；1–5 |

## Example

```ts
import { LogicalScatter } from '@a3d/a3d-components/map';
const scatter = new LogicalScatter(container);
scatter.setData([{ id: 'fault-1', x: 0.45, y: 0.55 }]);
scatter.setOptions({ pointRadius: 4, markerTone: 'red' });
scatter.setZoom(0.6);
scatter.dispose();
```
