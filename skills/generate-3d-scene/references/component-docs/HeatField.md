# HeatField

`import { HeatField } from '@a3d/a3d-components/map'`

栅格与建筑染色共享的数据场。generateHeatRecords(bounds,valueAt,options) 用于显式模拟：按当前单元大小逐格生成0–255整数，最多100000条，范围超限拒绝。不得用近似经纬度大步长制造稀疏网格，不修改样式补偿数据间隔。setData严格要求每格一值；重复或非法数据拒绝并保留上次有效状态。heatCellCenter(x,y,options)返回相对原点向东/向南整数格的经纬度中心。prepareHeatRecords(records,options,policy)显式转换：error（默认）/max/mean，mean四舍五入，返回records、inputCount、cellCount、mergedCount。非法数据不丢弃。先释放使用者，再释放场。

## Example

```ts
import { HeatField, heatCellCenter, prepareHeatRecords } from '@a3d/a3d-components/map';
const options = { origin: [121.49517, 31.24194] as [number, number] };
const [lng, lat] = heatCellCenter(0, 0, options);
const field = new HeatField(options);
field.setData([{ lng, lat, value: 180 }]);
// 仅业务明确需要取最大值时选择max；不默认聚合用户数据。
const prepared = prepareHeatRecords([{lng, lat, value:180}, {lng, lat, value:200}], options, 'max');
field.setData(prepared.records);
// 先销毁引用此场的GridHeat和BuildingTint。
field.dispose();
```
