# MapExperience

`import { MapExperience } from '@a3d/a3d-components/map'`

完整地图体验：统一管理底图、建筑、光影、双主题及地图交互。地图统一使用此入口，不要在同一容器创建两个地图。

## 创建

```ts
new MapExperience(options: MapExperienceOptions): MapExperience
```

## Example

```ts
import { MapExperience } from '@a3d/a3d-components/map';
import 'maplibre-gl/dist/maplibre-gl.css';
// container与styleUrl由应用提供；地标资产可通过assets显式传入。
const scene = new MapExperience({ container, style: styleUrl,
  center: [121.49517, 31.24194], mode: '3d', zoom: 16.2 });
scene.setParameters({ water: '#CEE3FD' });
scene.setTheme('dark');
scene.dispose();
```
