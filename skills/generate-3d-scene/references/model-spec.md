# model-spec — 模型规格（默认值与覆盖方法）

> validate-model.mjs 的机器执行面。写 AI 生成模型或评估入库资产时对照本文档。
> 阈值可 CLI 覆盖：`--max-triangles N --max-nodes N --max-texture-size N --max-textures N --origin-tolerance F --height-min F --height-max F`。

## 规格表（两档）

| 项 | art 档（默认） | strict 档（AI 生成） | 类别 |
|---|---|---|---|
| 面数（道具级 prop） | ≤5,000 | ≤2,000 | 性能·硬阻断 |
| 面数（主角级 main） | ≤50,000 | ≤10,000 | 性能·硬阻断 |
| 子节点数 | ≤64 | ≤64 | 性能·硬阻断 |
| 贴图尺寸 | 单张≤2048² | 单张≤1024² | 性能·硬阻断 |
| 贴图张数 | ≤8 / 模型 | ≤4 / 模型 | 性能·硬阻断 |
| 几何 | 必须含 POSITION attribute | 同左 | 性能·硬阻断 |
| 命名 | `^[a-z][a-z0-9_]*$` | 同规则 | 约定·默认告警（strict 阻断） |
| 原点 | 底面中心 y=0（bbox.min.y≈0，容差 0.01） | 同规则 | 约定·同上 |
| 世界高度 | 0.05~200 m 合理区间 | 同规则 | 约定·同上 |

- 档位切换：`--strict`；面数档位：`--profile main|prop`（默认 main）。
- 退出码：`0` 通过 / `1` 规格违规 / `2` 用法或解析错误。

## 每条规格的存在理由

- **面数**：场景总预算 ≤1M 三角（build.mjs 静态估算 + perf-fps 运行观测）。单模型 prop≤2k（多数几百）才能支撑「成百上千物体」的数字孪生规模；
- **子节点 ≤64**：扁平化节点树——深树遍历与序列化成本线性放大；骨架链（mixamorig*）天然超标属告警级；
- **贴图 ≤1024² / 图集优先**（strict）：贴图带宽与显存是批量场景第一瓶颈；art 档放宽到 2048 是第三方资产现实；
- **命名 snake_case**：编辑器槽位层（子网格材质编辑）以**名称路径**为 key——LLM 靠名字定位部件，无名 mesh 退化 `#N` 序号兜底（改名即失效）；
- **原点底面中心 y=0**：摆放语义（position.y=0 即落地）。偏移原点的模型每次摆放都要补偿偏移量；
- **高度合理区间**：单位错乱的第一道防线（cm 当 m 的模型高 179m，一票识别）。

## 米制与坐标

- 单位**米**，+Y up，glTF 标准 -Z forward；
- 引擎**不做隐式缩放**（篡改资产语义会误伤 1:1 机械模型）——厘米资产的归一化是使用方责任：节点 `scale` 显式设置（mixamo 类约 `0.0056`~`0.01`），validate-model 高度告警即提示。

## 场景级预算（与单模型规格互补）

| 项 | 默认上限 | 口径 |
|---|---|---|
| draw calls | ≤400 | build.mjs 静态估算 + perf-fps 运行直读；**WARN 观测**（超限不阻塞，须回应） |
| 三角面 | ≤1,000,000 | 同上 |
| 材质数 | ≤32 | 同上 |
| fps | p95 ≥40（真机 GPU） | WARN 观测；软渲染数值不判断 |

`--strict`（build/perf-fps 同款开关）恢复阻断口径。同类物体 >1000 实例才强制 InstancedMesh（≤1000 普通 mesh + 静态几何合并）。

## 与降级阶梯的关系

- 第 4 层「LLM 直写」产出的**实体 GLB**（入库复用）→ strict 档全量门禁（AI 资产是约定纪律的真正保护对象）；
- handler 过程化产物（代码组合模型，不产 GLB）→ 不走本门禁，走 build.mjs 场景预算；
- 入库第三方资产 → art 档（性能硬门禁 + 约定告警记录 deviations）。
