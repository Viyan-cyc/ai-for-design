# 修改已有场景

新建场景流程、选材、构建覆盖和修复额度以 [SKILL.md](../SKILL.md) 为准。本页用于局部修改、编辑结果回写和定向诊断，不重新执行新建流程。

## 定位工程与变化范围

1. 按主入口「开发工作区与交付目录」确定最新源码所在工程，读取相关 scene-data、注册项、handler 或外观文件。若用户已修改交付 source，以该版本为依据；来源不清且存在分歧时先确认，不覆盖。
2. 明确本次涉及的节点、参数和资源。沿用稳定 ID、槽位路径及用户编辑结果；不要为了命名风格调整既有名称。修改已有场景不运行 init，不用 demo 覆盖，不重新读取无关领域文档。
3. 按下表执行，再按主入口统一构建。只有新接口或新领域需要时才补读对应文档；会话内已读取且未变化的规则不重复加载。

| 修改类型 | 必要操作 | 资产操作 | 构建 |
|---|---|---|---|
| 位置、数量、相机 | 修改对应 scene-data；有配方时核对生成范围，保留范围外节点和人工编辑 | 引用不变则不检索、不下载 | 修改完成后一次统一构建 |
| 颜色、材质、贴图 | 按现有外观体系修改默认外观或编辑覆盖；先检查 __visuals/__materialLib，避免被旧覆盖遮蔽，不清空无关覆盖 | 沿用已物化资源；仅处理新增贴图依赖 | 同上 |
| 新增对象类别 | 检查已有资产与注册项，只为未覆盖的新类别按主入口选材 | 只检索缺项并注入选中资源 | 同上 |
| 更换模型或更新上传包 | 按 [designer-assets.md](designer-assets.md) 更新，保留未变项 | 内容或依赖变化时不能复用旧确认；文件名相同不代表内容相同 | 同上 |
| 数据接入、卡片、行为 | 修改相关 business 文件或 handler，按需查 scene-engineering.md | 模型引用未变则不重新下载或确认 | 同上 |
| 纯说明文档 | 仅修改说明和检查链接 | 无 | 不构建 |

源码、GLSL、几何、材质、场景数据或运行资源变化，都需更新预览，不交付旧包。集中完成本轮修改后构建；失败使用主入口的同一批修复额度，不因内部子步骤重置。构建成功后停止，已明确发现的功能错误仍应修复重建。

已有资产的确认复用以内容及依赖未变为前提；不重新检查未变化的库模型。布局生成器输出候选后仅合并本次范围，不能整份覆盖用户场景。无需为普通修改另写 Spec 或验证报告。

## 交付冲突

在当前项目的 `source/` 中修改，构建更新同一个 `index.3d.html`。构建依据产物清单更新预览文件，其余文件保持原样。检测到已有产物被改动或输出路径冲突时，停止发布并报告具体路径，由用户决定如何处理。

旧工程收到构建脚本版本提示时，将当前模板的 scripts/build-offline.mjs 与 scripts/publish-preview.mjs 更新合入 source/scripts，保留用户定制后继续在原项目构建。旧 node_modules、缓存及产物不会被自动删除。

## 编辑结果回写

- 开发模式保存直接写回工程 `public/scene3d/scene-data.json`。
- 离线模式保存复制 `scene3d-changes` 修改文本；剪贴板不可用时显示文本框。复制不表示源码保存成功，也不清除未保存状态。用户回传后由 Agent 回写。
- 核对 sourceId 与对应工程，逐项比较 before；冲突先处理，不覆盖其他修改。path 是路径数组，缺少 after 表示删除，数组整体替换；保留图片 data URI，或落盘后更新引用。
- 回写场景数据，不改业务 handler 或原 HTML；回写后统一构建。退出编辑只进入当前内存预览，可返回编辑，不等于保存。
- 旧 JSON 存档导入仅为兼容恢复，保证同源预览；源码变化重新构建后可能因 sourceId 不同而拒绝旧存档，不把它描述成默认保存下载流程。

## 定向诊断与按需交付

- 白屏、交互错误或卡顿：围绕报告的问题诊断，不默认追加全套浏览器、截图或性能采样。
- 调试注入：`node scripts/ensure-env.mjs --diagnose` 只报告是否检测到注入。若出现 Waiting for the debugger to disconnect，关闭宿主终端自动附加后比较同一命令，不全局清空 NODE_OPTIONS。类型检查由统一构建入口在工程外执行。
- 用户明确要求开发服务联调：在 source 执行 npm ci 后运行 npm run dev，保留贴图上传能力。这是开发者安装流程，会产生本机 node_modules；默认生成预览使用统一离线构建。
- 用户要求无编辑器源码：使用 scripts/strip-edit.mjs；自动剥离并编译已保存外观，TRANSCRIPTION.md 是自动摘要，无需人工转录。源码包不等于已部署网站。
- 用户要求部署：按目标环境构建，普通网页构建使用 npm run build。上述操作均非默认生成步骤。
