## 0. 概述与 Token 使用规则

Design Token 将样式名称与实际用途、语义和状态对应。业务组件引用 Token，底层数值集中在主题适配层；组件库的实际变量名可以不同，但颜色必须映射到本文件。

### 0.1 使用规则

- 默认浅色软件界面，直接使用本包 GTS 颜色，不询问用户选择另一套配色。深色主题使用第 1.2 节统一表的 Dark 列，经 `html[data-theme="dark"]` 整体切换，不逐组件挑选颜色。
- 先确定组件部位、用途及状态，再取对应 Token。填充、文字、图标、边框和弱背景分别选色，不能按相近色值互换。
- 保留 Token 名称、大小写和单位，使用 ASCII 连字符；`*` 只表示系列，实际代码需展开成存在的 Token。
- 同一配置下，一个 Token 只对应一组值。常规／紧凑间距分别按表使用，不随视口整体缩放。
- 保留有明确值的颜色和 alpha；不得从相似颜色、固定透明度或反色推导缺失状态。
- 默认、悬停、按下、聚焦、选中、禁用、加载、错误等状态按组件能力实现。重要含义同时使用文字或图标，禁用时实际阻止交互。
- 未定义或待确认的值不可使用；页面确实需要时补齐本包 GTS 定义后再实现，不沿用旧样式填补。

### 0.2 命名与用途

| 类别 | 命名示例 | 使用方式 |
| --- | --- | --- |
| UI 语义色 | `color-brand`、`color-text-primary`、`color-border-focus` | 优先按部位与状态使用 |
| 基础色板 | `brand-50`、`gray-90`、`red-05` | 按用途映射到主题层，不能自动当作组件默认值 |
| 代码与公司辅助色 | `code-keyword`、`company-blue` | 仅用于对应场景；本包检索键不等于库 API |
| 尺寸与排版 | `space-size-16`、`radius-size-normal`、`font-size-normal` | 参数表中的实际名称和值 |
| 投影 | `shadow-1`、`shadow-2-left` | 几何、方向和 alpha 见投影表，颜色引用 `gray-100` |
| 毛玻璃材质 | `--frost-blur-*`、`--frost-surface-*` | 仅用于材质扩展，成套取值；参数见第 7 节 |

### 0.3 项目接入与颜色核验

- 页面、导航、表格、表单、按钮、下拉面板、弹窗、Tooltip、消息、图表和代码区统一使用本文件；挂载到 body 的浮层也必须获得相同的颜色变量。
- 组件库通过主题接口或集中封装映射到本包 Token；不能直接使用库的默认配色，也不能在局部组件中保留另一套颜色表。
- 不读取旧项目的配色选择字段来改变本包颜色。接入已有页面时，按用途逐项更新全部颜色引用、图表序列与局部覆盖；完成前不声明已完成迁移。
- 非颜色的尺寸、布局、交互与国际化规则按相应章节执行。真实图片内容和业务对象自选颜色不作 UI Token 限制；可控图标、SVG 状态色及图表颜色需纳入检查。
- 图表默认使用 `default` 六色序列；需要无障碍图表时使用完整 `accessible` 序列，这是同一颜色表内的用途配置，不触发配色体系选择。
- StarCode 的深色代码区只影响代码容器，不赋予全页面深色支持。全页面深色使用第 1.2 节统一表的 Dark 列经主题切换提供。
项目侧以颜色绑定清单记录实际使用的颜色用途（最小格式如下；`theme` 缺省为 `light`，`chartPalette` 缺省为 `default`）。绑定核对由消费侧工程门禁承担。

```json
{
  "schema_version": 2,
  "bindings": {
    "button.primary.background": {"token": "color-brand"},
    "page.background": {"token": "color-bg-1"},
    "text.primary": {"token": "color-text-primary"}
  }
}
```

检查限定本文件定义的颜色 Token，拒绝未定义键、待确认值、局部 value 或 fallback。还需核对实际代码、库主题及浏览器样式，不能用一份绑定记录替代页面验收。

## 1. GTS 颜色

### 1.1 使用边界

- 软件产品默认高亮色为 `brand-50`（`#0067D1`）；门户官网的高亮建议使用 `gray-90`（`#191919`），不改变全套 GTS 配色。门户高亮完整状态尚未给出，需要时先补齐参数，不套用软件蓝色状态。
- 基础色板灰阶以 `gray-0`（白）至 `gray-100`（黑）命名，端点纳入同一数轴；基础色阶按下表统一大小写。
- `focus` 在部分用途说明中标为选中／高亮，按实际组件映射；键盘聚焦仍需单独保持可见，不把选中与聚焦当成同一行为。
- `#RRGGBB / N%` 表示颜色层以 N% 不透明度叠加，实现时转换为 rgba；不能透明化整个组件。
- UI 表提供浅色／深色两主题的值（浅色软件界面默认浅色列）；代码区的浅／深值仅用于代码区。功能色完整交互态、门户状态及未明确的组件部位参数不能自行推算。

### 1.2 UI 语义色

统一 `Token｜用途｜Light｜Dark` 四列定义：英文 Token 是标识，用途决定使用场景，Light／Dark 分别对应浅色／深色主题；同一作用域内每个 Token 只有一个值。`subtle`／`subtler` 是同一主题内的色面强弱，不是主题切换。深色在 `html[data-theme="dark"]` 生效，挂载到 body 的浮层、图表与代码区继承同一主题；缺失引用应报错，不回退另一主题或库默认色。透明色 `#RRGGBB / N%` 表示颜色层不透明度，转换为 rgba 使用，不对整个组件设置 opacity。

### 2.4 边框与内间距

- 组件内间距标注包含边框宽度。实现时，单侧 `padding + border-width` 等于目标间距。
- 按钮单侧目标内间距为 16px、边框为 1px 时，`padding` 为 15px。
- 输入框外边缘至输入文字的距离为 12px、边框为 1px 时，`padding` 为 11px。
- 标签与输入框之间的 8px 为组件外部间距，不重复计入输入框边框。
- 穿梭框等复合组件按内部各区域的间距配置布局，不将外层间距统一套用到所有内部区域。

深色列仅保留边框尺寸参数，不代表完整深色 UI 配色已定义。

| Token | 用途 | 浅色主题 | 深色主题 |
| --- | --- | --- | --- |
| `border-width-none` | 无边框 | 0px | 0px |
| `border-width-normal` | 正常边框 | 1px | 1px |
| `border-width-medium` | 获焦边框 | 2px | 2px |
| `border-width-independent` | 按主题显示边框，如对话框 | 0px | 1px |

### 4.2 类型

| Token | CSS 值 | 形态 |
| --- | --- | --- |
| `border-style-dotted` | `dotted` | 点状线 |
| `border-style-dashed` | `dashed` | 虚线 |
| `border-style-solid` | `solid` | 实线 |

### 4.3 使用规则

- 宽度、线型、颜色分别配置；边框颜色按组件状态使用中性色、系统高亮色或功能色 Token。
- 普通描边使用 `color-border`；悬停使用 `color-border-hover`；获焦使用 `color-border-focus`；禁用使用 `color-border-disabled`；分割线按强弱使用 `color-border-separator`／`color-border-separator-subtle`。
- 获焦边框使用 `border-width-medium`，同时保持焦点可见。
- `border-width-independent` 用于浅色无边框、深色有边框的组件，不作为所有组件的默认值。
- 内间距包含边框宽度，按[边框与内间距](#spacing-box)计算，避免边框导致内容区尺寸变化。

## 6. 阴影与投影

### 6.1 阴影层级

| 层级 | 用途 | 典型场景 |
| --- | --- | --- |
| Level 0 | 无阴影 | 输入框等贴合基准面的组件 |
| Level 1 | 低层级投影 | 卡片、侧边导航 |
| Level 2 | 展开并跟随触发元素的浮层 | 下拉面板 |
| Level 3 | 高层级悬浮区域 | 抽屉、对话框、气泡提示、卡片悬浮态 |

### 6.2 阴影参数

所有阴影均为外阴影，颜色引用 `gray-100`（`#000000`），几何与不透明度按下表使用；X、Y、模糊、扩展的单位均为 px。几何由场景决定，主题仅改变 alpha：两主题同一几何，深色 alpha 更高。

| Token | 层级 | X | Y | 模糊 | 扩展 | Light alpha | Dark alpha |
| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `shadow-1` | Level 1 | 0 | 1 | 3 | 0 | 10% | 24% |
| `shadow-2-left` | Level 1 | 1 | 0 | 6 | 0 | 10% | 24% |
| `shadow-2-right` | Level 1 | -1 | 0 | 6 | 0 | 10% | 24% |
| `shadow-3` | Level 2 | 0 | 4 | 8 | 0 | 20% | 32% |
| `shadow-4-top` | Level 3 | 0 | 4 | 12 | 0 | 10% | 40% |
| `shadow-4-bottom` | Level 3 | 0 | -4 | 12 | 0 | 10% | 40% |
| `shadow-4-left` | Level 3 | 6 | 0 | 18 | 0 | 10% | 40% |
| `shadow-4-right` | Level 3 | -6 | 0 | 18 | 0 | 10% | 40% |
| `shadow-5` | Level 3 | 0 | 6 | 20 | 0 | 10% | 40% |
| `shadow-6` | Level 3 | 0 | 20 | 32 | 0 | 10% | 48% |

### 6.3 组件应用

| Token | 适用场景 |
| --- | --- |
| `shadow-1` | 卡片、单选框页签型、记分卡 |
| `shadow-2-left` | 左侧导航 |
| `shadow-2-right` | 右侧导航 |
| `shadow-3` | 回到顶部、滑块、选择器下拉菜单、日期选择器、下拉菜单、颜色选择器、级联选择器、警告、消息、通知、右键快捷菜单 |
| `shadow-4-top` | 顶部抽屉 |
| `shadow-4-bottom` | 底部抽屉 |
| `shadow-4-left` | 左侧抽屉 |
| `shadow-4-right` | 右侧抽屉 |
| `shadow-5` | 卡片 Hover／Selected 态、气泡提示 Popover、文字提示 Tooltip |
| `shadow-6` | 穿梭框、对话框 |

方向后缀 `t`、`b`、`l`、`r` 表示组件所在方位；阴影向页面内容区域投射，偏移正负值按参数表使用。

### 6.4 不透明度配置与实现

- 各投影另有 80% 不透明度配置，适用主题未明确；仅在主题配置明确指定时使用，不自动套用到深色主题。深色主题 alpha 按 6.2 参数表 Dark alpha 列使用。
- `box-shadow` 的值依次为 X 偏移、Y 偏移、模糊半径、扩展半径、颜色。外阴影省略 `inset`，不写 `outset`。
- 默认 `shadow-1`：`0px 1px 3px 0px rgba(0, 0, 0, 0.1)`；启用 80% 配置时仅将 alpha 改为 `0.8`。
- 业务组件引用投影 Token，不直接复制底层 CSS 值。

## 7. 毛玻璃效果

### 7.1 用途与边界

- 普通业务页面默认实色。仅在需要材质强调的标签、次级按钮、概览卡片和轻量浮层中启用毛玻璃。
- 毛玻璃是材质扩展，不改变 GTS 品牌色、功能色、交互语义、组件结构和尺寸；圆角按[圆角规范](#radius)及具体组件部位取值。
- 默认中性磨砂，浅色用中性白、深色用中性深灰（参数见[材质档位与 Token](#frost-presets)）；深色材质随深色主题参数生效，不因本节提及深色而自动启用整页深色主题。
- 实现顺序：确定使用场景 → 选择档位 → 核算面积 → 配置背景与材质 → 保留交互语义 → 验证回退、可读性与性能。

<a id="frost-presets"></a>

### 7.2 材质档位与 Token

| 档位 | 用途 | 选择规则 |
| --- | --- | --- |
| `control` | AI 建议、推荐标签、次级工具按钮 | 同一区域突出 1–3 个，主操作和告警保留原语义 |
| `card` | 指标、智能摘要、概览卡片 | 默认白色磨砂与受控柔和背景；同屏重点卡通常 1–3 张 |
| `overlay` | 菜单、浮动工具条、轻量面板 | 背景复杂时优先提高填充不透明度；长篇内容使用实色 |

同一档位成套使用模糊、填充与阴影参数，不逐组件自由生成数值。面积变大不自动提高模糊强度，先判断背景复杂度与文字可读性。

| Token／检索关键词 | 用途 | 参数 |
| --- | --- | --- |
| `--frost-blur-*` | 各档位背景模糊 | `control` 12px、`card` 20px、`overlay` 28px（Light／Dark 相同）；饱和度 `--frost-saturate-neutral` 100%、`--frost-saturate-muted` 95% |
| `--frost-surface-*` | 各档位中性磨砂表面 | 浅色 `rgba(255,255,255,α)`、深色 `rgba(25,25,25,α)`；α 按档位 control `.68/.64`、card `.76/.72`、overlay `.84/.80`（light/dark）；交互增量 hover `+.04`、active `+.08`，见[交互状态与回退](#frost-states) |
| `--frost-shadow-*` | 各档位阴影 | 浅色：control `0 2px 6px rgba(0,0,0,.04)`、card `0 6px 18px rgba(0,0,0,.06)`、overlay `0 10px 28px rgba(0,0,0,.10)`；深色同几何，色为 `rgba(0,0,0,.12/.18/.24)` |
| `--frost-backdrop-*` | 独立父级柔和渐变背景 | 基色 light `#F3F3F3`／dark `#191919`；blue `#8ABEF3` alpha `.28/.16`、lavender `#BFB9FA` alpha `.18/.10`、teal `#8FE5C2` alpha `.10/.06`（light/dark）；渐变为两个 radial：`ellipse 70% 100% at 15% 20%`（blue，72% 处透明）＋ `ellipse 65% 90% at 90% 75%`（lavender，75% 处透明），可经 `--frost-backdrop-gradient` 整体引用 |
| `--frost-tint-blue`、`--frost-tint-lavender`、`--frost-tint-teal` | 可选薄染色层 | 浅色 `#5CA2E9` alpha `.08`／`#A89FF9` alpha `.06`／`#63D5A8` alpha `.05`；深色 alpha `.10/.08/.07` |
| `--frost-border` | 辅助材质边界 | light `#595959 / 14%`、dark `#FFFFFF / 14%`；宽度引用标准边框 1px |
| `--frost-surface-solid` | 减少透明度及不支持模糊时的不透明表面 | 不透明度 100%；light `#FFFFFF`／dark `#2A2A2A` |
| `frost-common`、`frost-light`、`frost-dark` | 公共参数、浅色／深色材质参数组 | 组名为检索关键词，不是可直接引用的 CSS 变量；公共：hover／active 填充增量 `+.04/+.08`、过渡 `120ms ease-out`、描边宽度引用 `--border-width-normal`、描边色按 `--frost-border` 使用 |
| `frost-decoration` | 色块磨砂装饰参数组 | 全部参数见[色块装饰](#frost-decoration)装饰参数表 |

`--` 表示 CSS 自定义属性，`*` 仅表示系列。染色、氛围与边界色均取自第 1.3 节公司色板端点（`brand-30`、`indigo-20`、`mint-20`、`gray-60`），不引入色板外色相；中性表面深色 `rgba(25,25,25,α)` 对应 `gray-90` 通道值。

<a id="frost-budget"></a>

### 7.3 应用面积

| 对象 | 建议比例 | 上限／计算口径 |
| --- | --- | --- |
| 常驻毛玻璃总面积 | 主内容视口的 10%–20% | 上限按 25% 控制，不必用满 |
| 淡彩毛玻璃 | 少量使用 | 不超过主内容视口的 8%，计入总面积 |
| 单张重点卡 | 控制面积 | 建议不超过主内容视口的 12% |
| 小标签 | 主内容视口约 1% 以内 | 计入总面积 |
| 工具按钮 | 主内容视口约 2% 以内 | 计入总面积 |

- 按可见毛玻璃表面的并集计算，重叠只算一次；底层渐变不计入模糊面积。临时浮层单独评估。
- 常驻侧栏、表格行、单元格、编辑表单和长篇内容使用实色。
- 一个位置只保留一层背景模糊；毛玻璃卡片内的按钮和标签使用实色或透明填充，不再开启 `backdrop-filter`。
- 面积预算不能代替目标设备上的性能测试。

<a id="frost-background"></a>

### 7.4 背景与染色

- 从底到顶依次为：中性基底 → 边缘缓慢淡出的雾蓝／灰紫渐变 → 中性毛玻璃填充与背景模糊 → 清晰内容。渐变放在独立父级 `.g-frost-backdrop`。
- 默认白色磨砂；深色使用对应中性深灰。淡彩通过薄染色层叠加，一页优先一种染色，不表达成功、告警等功能状态。背景及染色使用前须补齐[材质 Token](#frost-presets)。
- 背景默认静态、大范围淡出，避免鲜艳色块、彩虹分段、持续漂移和发光轮廓。
- 默认不提高背景饱和度；复杂背景可选择 `muted` 降低饱和度，具体参数须统一定义。纯色背景没有可模糊细节，不通过持续提高 blur 补偿。
- 只调整填充层的 alpha，不设置整个组件的 `opacity`；文字、图标和焦点轮廓保持清晰。

<a id="frost-states"></a>

### 7.5 交互状态与回退

| 状态／条件 | 规则 |
| --- | --- |
| Hover／Active | 只调整填充层的 alpha（hover `+.04`、active `+.08`，同档位表面色相不变）和阴影；不改变 blur。active 档阴影为 none |
| Focus／Selected | 焦点保持当前填充，加 2px `color-border-focus` 外轮廓，偏移 2px；选中保留品牌边界或标记，不以材质代替状态 |
| Disabled | 使用原禁用语义、阻止交互：有描边控件用 `color-fill-disabled-subtle`，无描边用 `color-fill-disabled`；文字／边框用对应禁用 Token，关闭模糊、染色和阴影 |
| 多层嵌套 | 停止内层背景模糊 |
| 不支持 `backdrop-filter`／减少透明度／产品主动降级 | 使用 `--frost-surface-solid` 完全不透明表面；作用域可设置 `data-transparency="reduced"` |
| 减少动态效果 | 关闭过渡 |
| 高对比模式 | 使用系统颜色，保留内容与重点层级 |

按实际合成背景检查文字可读性，普通文本对比度至少 4.5:1。切换背景、滚动位置及已支持主题后仍须清晰；编译通过不等于视觉验收通过。

<a id="frost-decoration"></a>

### 7.6 品牌色块磨砂装饰

品牌重点卡保留不透明色底与统一白字，通过同色相弱渐变和边角磨砂图形丰富留白。此变体与整块浅色毛玻璃独立，不为添加装饰而将品牌色块改为浅色。

#### 选用规则

- 区域承担总览、主指标或品牌展示，存在大面积单调色底，且边角能避开文字时，可在生成页面时选用。参考尺寸至少 240 × 112 CSS px；尺寸达标不代表必须装饰。
- 同一组默认只选 1 张主卡，同屏通常 1 处、最多 2 处。无色底或内容密集的大卡片保持原样；用户要求简洁或不装饰时关闭。
- 普通卡片、导航、按钮、表格、表单、图表绘图区，以及告警／成功语义色块不使用此装饰。

#### 装饰参数

| 参数 | 规范值／方法 |
| --- | --- |
| 图形数量 | 1–2 个裁切圆形或圆角图形 |
| 默认位置 | 右上和右侧，避开文字 |
| 装饰可见面积 | 宿主面积的 10%–20%，不超过 25%；计入毛玻璃总面积预算 |
| 图形填充 | 白色（`gray-0`），不透明度由 10% 淡至 2.5% |
| 图形描边 | 白色（`gray-0`），不透明度 13%；描边宽度引用 `--border-width-normal`（与宿主组件描边一致） |
| 图形模糊 | 引用 `control` 档，不单独编造模糊值 |
| 底色 | 品牌蓝渐变 `linear-gradient(115deg, var(--frost-decor-brand-start) 0%, var(--frost-decor-brand-start) 60%, var(--frost-decor-brand-end) 100%)`，起始色 `brand-50`（`#0067D1`）、浅蓝端点 `brand-40`（`#2E86DE`），文本位于起始色区域；不新增紫、粉等色相 |
| 内容色 | 标题、数字和标签统一使用 `color-text-inverse`，通过字号与字重区分层级 |
| 尺寸档位 | 默认 `card`（装饰缩放 1），宽幅概览可用 `panel`（缩放 1.35）；几何：圆形直径 146px（top -88px／right 2px），圆角块 86px（top 42px／right -52px，圆角 20px，旋转 -24°） |

- 层次为：同色相弱渐变底 → 边角磨砂图形 → 清晰内容。趋势配合正负号或文字，按合成底色检查白字对比度，避免高光压住文本。
- 宿主保持不透明色底、原有圆角、尺寸与业务布局；不同时启用整块毛玻璃，也不嵌套背景模糊。
- 装饰使用无语义伪元素，不拦截点击、不进入键盘焦点；与组件已有伪元素或定位子项冲突时，使用专用容器。
- 不持续播放动画，不为凑面积比例放大图形。关闭装饰、减少透明度或高对比模式时，保留清晰内容和重点层级。

## 8. 状态对位与调用要求

### 8.1 状态规则

| 对象 | Default／Hover／Active | Focus／Selected | Disabled |
| --- | --- | --- | --- |
| 品牌控件 | brand／brand-hover／brand-active | brand-focus 标识选中；键盘焦点另用 border-focus 轮廓 | brand-disabled；同时用禁用文本并阻止操作 |
| 文本链接 | link／link-hover／link-active；已访问用 link-visited | 当前文本色加 border-focus 轮廓；链接语义保留 | link-disabled，阻止操作 |
| 功能控件 | 同一功能组的基础／hover／active；信息主色用 info-primary 系列 | 保留当前功能填充，加 border-focus 轮廓和选中标记 | 同组 disabled；禁用行为生效 |
| 表格行／选项 | 普通行透明，交替行 table-zebra；Hover 用 color-hover，替代 zebra；Active 保持当前填充 | Selected 用 color-select，替代 Hover／zebra；选中悬停仍用 select；Focus 另加轮廓 | 按控件是否有边框选禁用填充，不响应悬停与按下 |
| 输入与选择控件 | color-fill-subtle；边框用 border／border-hover；输入指定边框用 border-active | border-focus 与 2px 边框 | fill-disabled-subtle／text-disabled／border-disabled |
| 毛玻璃 | 按 7.5 各态值 | 清晰轮廓及选中标记 | 禁用语义并去掉材质效果 |

表格背景、斑马纹和分割线分别引用 `color-table-header`、`color-table-zebra`、`color-border-separator-subtle`；表格内控件边框仍使用 `color-border`。背景状态只保留一个填充层，避免 Hover、Selected、zebra 叠加变色。加载态保留所在组件当前配色并阻止重复提交；错误态同时呈现错误文字或图标。

### 8.2 文本与背景配对

颜色角色不能替代对实际背景的检查。主要正文使用 `color-text-primary`；次要、占位、已访问链接和品牌按钮文字需逐态核验。

- Light 的 #777777 对白色约 4.48:1，普通正文使用 `color-text-primary`；占位文字不能替代可见字段标签。
- Dark 的 #939393 对 #393939 约 3.76:1，普通说明文字使用 `color-text-secondary`；#5CA2E9 链接对该背景约 4.29:1，此处采用可读的文本层级并保留链接下划线／图标。
- Dark 的已访问色 #715AFB 对 #191919 约 3.82:1；小字号场景采用可读文本层级，以额外图标或文字表达访问状态。
- 白字对 #2E86DE 约 3.77:1。小字号品牌按钮 Hover 的前景使用色板 `gray-90`（#191919，约 4.67:1）；Default／Active 前景用 #FFFFFF。功能实色面同样逐态选取通过目标的色板文字色，不统一套白字。
- 焦点使用 `color-border-focus`；遇到与背景不足 3:1 的组合，加一层可见中性轮廓。不能用阴影、透明度或颜色变化作为唯一焦点提示。

### 8.3 接入与核验

按“组件部位 → 状态 → theme → chartPalette／材质档位”取值。生成器展开实际 Token，不将系列通配符当变量；检查 Light／Dark 均有值、引用键存在、透明度只施加一次。页面、弹层、表格、图表与材质回退分别做明暗主题和交互状态验证；构建通过不等于视觉与可访问性验收通过。

### 7.7 实现与调用约定

以下为项目样式适配层的调用约定，不是 Element Plus 的原生 API。使用真实组件，通过封装或主题样式承载材质；须实现对应样式并确保属性作用于目标元素，仅添加属性不会自动产生效果。

| 调用标记 | 用法 |
| --- | --- |
| `.g-frost-backdrop` | 承载独立柔和背景 |
| `data-material="frosted"` | 显式启用整块毛玻璃 |
| `data-frost-level="control\|card\|overlay"` | 选择一个材质档位；省略时默认 `card` |
| `data-frost-tint="blue\|lavender\|teal"` | 可选薄染色；不设置时为中性磨砂 |
| `data-frost-tone="muted"` | 降低背景饱和度 |
| `data-surface="brand"` | 品牌蓝底色与白字 |
| `data-decoration="frosted"` | 独立启用色块磨砂装饰，不同时设置 `data-material="frosted"` |
| `data-decoration-size="panel"` | 宽幅装饰比例；省略时为 `card` |
| `data-transparency="reduced"` | 在作用域内关闭透明材质，使用实色回退 |

表内 `\|` 表示可选值，实际属性只填写一个值。需要页面级风格配置时，可用 `visualStyle: "frosted-glass"` 表达材质意图，仍逐区域遵循用途与面积预算，不自动作用于全部组件。

在主题层集中定义参数，通过 `backdrop-filter` 实现背景模糊；为不支持该能力、减少透明度和高对比环境实现对应回退。接入旧 `aurora-glass`、`--glass-*` 或 `.g-glass-*` 时，先明确映射到已补齐的 `frost` 定义，再逐项验证；不直接引入另一套颜色或旧参数。

### 7.8 不要

- 不将整页、常驻侧栏、密集表格或编辑表单统一改为毛玻璃。
- 不把材质、染色或装饰用作成功、告警、禁用、选中等语义的唯一表达。
- 不使用未定义参数、自由生成模糊值，或复制旧材质参数补缺。
- 不模糊文字、降低整个组件透明度、叠加多层背景模糊或遮挡焦点。
- 不为装饰改变组件圆角与布局，不因存在风格配置就自动填满面积预算。
