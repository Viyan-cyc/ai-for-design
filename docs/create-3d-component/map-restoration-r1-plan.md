## 当前包与清理后的接口

只读解包证据r1-package.json：内置0.1.0包具有./map入口、MapRuntime/MapPresentation/MapSurfaceParticleScan/MapHeatLayer/MapScatterLayer声明与实现；没有./scatter、./map-design、HeatDelivery。R2需用清理后的库重新prepare组件同步，审核changes再apply，不手改tgz。

首次同步必须按`map-restoration-r1-sync.md`执行：当前无归属manifest，旧包、catalog及32份组件页逐项符合接管标记规则。先完成批准的人工删除/编辑（包括两份撤销API页），再使用`--adopt-generated` prepare；catalog由生成器接管重建，不人工修改。prepare后输入变化须重新prepare；人工文件不得接管。附件列明精确命令、逐文件资格、差异审核及拒绝保护测试，不能省略该前提直接apply。

保留MapConfig.overlays兼容空数组：缺省或[]允许；非数组或非空数组在validateMapConfig中、创建资源/更新现有状态之前明确拒绝。不能从旧配置中静默删除业务数据。序列化维持overlays:[]，基本地图surface列表不含overlay项。移除MapOverlays构造/释放/更新/列表分支，相关Vue卡片覆盖层逻辑不再打包；其他场景卡片注册机制保留。
