# B5试填：办公室休息室

本文件是可审阅设计草案，不是生成工程或运行配置。

## 1. 身份、来源与适用范围【必填】

标识：b5-interior-v1；版本：2026-11-07。普通Three房间去顶斜俯视与家具编辑；不是建筑施工图，不新增动态剖切、物理碰撞或第一人称。

设计状态：12×8×3.2米来自用户本项目需求；温暖明亮的具体方案为建议，未由设计师确认。

来源索引：common / types / focus / save / workflow；用户办公室需求。输入版本见[digital-twin-b5-sources.json](digital-twin-b5-sources.json)的路径与SHA-256；该清单仅审计，不是运行配置。项目需求依据本会话用户明确给出的三段prompt。维护责任：设计由用户／设计师确认，字段与能力由Skill维护开发核对。

实现状态：复用现有接口；实例尚未生成，功能和效果未验收。本版首次试填，未改变存储字段或已发布默认。

## 2. 表达目标【必填】

面向室内布局与家具编辑：优先看清窗边休闲区、中部茶几单椅与侧面茶水区。温暖明亮，木、织物、金属、玻璃可区分；生活细节辅助空间尺度。

## 3. 布局与尺度【必填】

本次房间12米长、8米宽、3.2米高，单位米。一侧落地窗和沙发区，中间茶几／地毯／单椅，另一侧茶水柜、咖啡机、小冰箱和吧台，入口旁储物柜绿植。家具真实占地由资产尺寸核对，座位与通行空间连通；不把本项目房间尺寸作为室内默认。初始去顶、隐藏靠近镜头的遮挡墙，同时保留可编辑墙节点；相机旋转后自动隐藏前墙是未启用候选，不冒充已有功能。

## 4. 配色与表面表现【必填】

| 角色 | 设计意图 | 参数来源 | 覆盖范围 | 状态 |
|---|---|---|---|---|
| 墙面／织物 | 米白墙、浅灰织物，哑光与细微材质差异 | 项目材质，精确色值／roughness待确认 | 指定对象材质 | 建议 |
| 木／金属／玻璃 | 浅木色、少量金属点缀、克制玻璃反射 | 原资产PBR材质优先 | 按材质支持调整 | 建议 |
| 植物／地毯 | 少量绿色、地毯划分休闲区 | 项目对象材质 | 对象级覆盖 | 建议 |

本实例无告警数据；若将来加入，颜色必须配文字／图例且另核对语义。不透明度100%表示不透，与透明度反向；不把材质opacity与地图图层不透明度混为同字段。

## 5. 相机与浏览【必填】

从房间一角斜俯视，完整呈现家具关系；以室内业务包围盒计算position/lookAt与控制距离，避免贴墙穿透。Orbit旋转缩放平移沿用现有行为，裁剪距离按房间范围核对。使用当前FOV，不提前实现焦距控件或视角预设。

响应视口设计：桌面横屏总览，窗口缩窄后优先保留当前观察目标和用户旋转状态；标签避免挡住主体，属性面板保持可滚动。自动重新取景、面板窄屏收起与标签避让的当前支持待开发核对，不宣称已实现；以横屏→窄窗→恢复用例确认，若现有控件无法操作则报告限制。没有已实测的最小窗口尺寸，本方案不承诺手机适配。

### 6.1 光照与渲染

使用当前渲染配置，不从案例抄pixelRatio、MSAA、shadowMapSize或帧率作为全设备最优。画质沿用现有档位，是否适合由后续实际设备／分辨率测试确认。场景亮度与材质可读性是设计目标，环境贴图不等于环境光、曝光不等于灯光强度。精确强度由实际场景验证，未知值由开发核对、用户确认效果。

### 6.4 交互与编辑

沿用现有模型列表、对象／场景属性、眼睛、锁、撤销重做及唯一保存入口。支持对象类型见第8节；选中反馈退出应恢复，不改永久材质。开发保存回写scene-data；离线复制修改文本不代表已写回或清除未保存状态；回传后构建验证。按workflow“编辑与回传”约定，本轮仅引用，未重跑保存闭环。重置与预设只影响声明字段集合；未声明集合前不添加一键全局重置。
