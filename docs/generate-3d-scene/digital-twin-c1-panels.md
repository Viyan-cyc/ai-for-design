# C1 面板对应与条件显示设计

本轮是可交互设计示意，不是运行编辑器。保持现有 UI 令牌和入口，不复刻数字孪生 Step 面板。设计审核页的“宿主/对象”选择器仅用于检查条件，不进入产品。

## 面板分工

顶部负责项目操作；左侧负责模型、灯光、统计；右侧物体页负责选中对象，场景页负责全局设置；底部负责视口快捷操作。光源具体参数继续在现有场景页编辑，不新增第二套灯光编辑面板。

|---|---|---|---|---|

## 条件优先级与状态

宿主能力 → 选中对象类型 → 对象支持属性 → 开关与锁定状态。领域名称只选择默认方案，不决定底层能力；室内和工厂不会仅凭名称出现不同灯光控件。

无关能力隐藏；可以由用户补齐条件的项目禁用并解释；锁定时保留设置可见但不可编辑。切换标签页、隐藏控件不清空已保存值。没有对象时物体页提示选择；用户主动选场景页不应被每次参数变动强行切走。多选、混合材质及槽变换沿用现有逻辑，C4逐项验证，不在示意页伪造支持。

地图图层不提供Three材质、平移旋转或焦距；地图中的附加Three对象仍可编辑物体属性。地图宿主不能因选中Three对象而显示普通相机配置。普通场景的深浅当前不是完整材质主题，C1不悄悄扩大其语义。

## 不进入本轮面板

HSV/色温待D2/D3；日夜、碰撞、漫游待D4；爆炸、剖切、LOD待D5；业务联动待D6；单位切换、自定义键位、视角预设继续按A4延期。24小时弧线和全部参数接入状态不进入普通用户面板。开发诊断放开发资料，不当设计控件。

## 本轮可验证与后续

页面验证显示规则和归属；数值输入仅为说明，禁用，不保存也不修改真实场景。只有上方条件选择器与场景/物体页签驱动演示。后续C2改明确术语、C3实现焦距、C4选择首批实际显示规则、C5处理重复入口及保存范围。

检查：普通/地图、无选中/Three对象/地图建筑/地图水面、锁定、透视/正交、建筑显隐及投影支持。地图表面仅在地图选项下可选择；切换宿主会清除不适用的模拟选中，不代表生产选择策略改变。来源及哈希见digital-twin-c1-panels.json。
