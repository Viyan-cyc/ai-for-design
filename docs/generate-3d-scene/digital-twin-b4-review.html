# 真实地理地图设计指南

## 来源与适用范围

使用上海地图v2.97／v2.1设计基线的通用深浅主题，适用于真实地理底图、普通建筑白模及MapPresentation默认OpenMapTiles表现路径。用户已确认采用设计师地图方案作为地图风格依据；归档视觉说明标注其参数来自用户面板截图。此确认不覆盖后来新增的业务标签、热力策略、编辑器或算法改动，也不推广到工厂、室内的配色。

来源标识：`map-experience-v297/assets/上海地图-v2.97-基线-v2.1/v2.97样式参数-v2.1.json`，SHA-256 `faa521fe235b46f63e61cdcb506f643f9ed9e71cb7a7c81e8ea509e3dbf91af7`。原HTML指纹 `b7058768ae9dcac008b942059caf885a23657c759a1f93181777f8e0e3a050b7`。维护仓库B4记录保存逐键比较，不把这些机器参数再次复制为Skill运行配置。

## 表达目标与布局

浅色保持干净、低饱和的整体关系；深色使用中性地面、克制绿地与蓝灰水域。道路、岸线和主体建筑保持可读；白模表达实际数据可获得的体块关系，不承诺写实地标复刻。

真实建筑形状与高度、道路、水面、绿地由地图服务及数据决定；缺失信息如实说明。范围和初始取景根据项目地点及关注区域确定，避免无限背景挤小业务主体。示意布局另读[campus.md](campus.md)，不以虚构精模补成声称真实的数据。

## 唯一参数来源与接入

运行主题值由组件包`@a3d/a3d-components/map`的`MapPresentation`提供；当前内部实现为组件源码`src/map/map-experience.js`的`MapExperience.themeValues(mode)`。该方法是实现定位，不是供业务直接调用的公开API。通过现有场景`map.theme`选择light／dark；生成时不手抄72项主题常量，也不以无需求的surface覆盖固定住主题色。

底图地面、道路及描边、水域、绿地及分类型不透明度、建筑材质表现、天空、光照方向、投影与底图文字样式，均继承该预设。B4逐键核对两主题共72项通用值一致，颜色十六进制大小写视为等价；排除12项东方明珠专用值。该结论只证明当前源码主题常量，不证明所有算法或随附发布包完全一致。

已有工程显式覆盖按用户设置保留。`map.surfaces`及主题切换规则见[地图接入说明](../map.md)和[MapPresentation](../component-docs/MapPresentation.md)。提供`layerMapping`时走明确映射路径，仅控制映射图层的颜色和显隐，不保证完整OpenMapTiles主题算法。其他地图样式需先核对映射，不能宣称任意底图都还原本方案。

## 项目参数与性能

| 类别 | 使用方式 |
|---|---|
| 地点、中心、范围、zoom、bearing、初始pitch | 项目提供或按业务范围计算，不继承上海／福田绝对取景 |
| 地图深浅主题 | 选择上述实际预设，用户明确风格需求可覆盖 |
| 原始光照方位、建筑表现及投影 | 当前主题内部设计参数；不是相机方向，也不是Three灯光直接对应值 |
| pixelRatio、抗锯齿、阴影分辨率、帧率、按需／持续渲染 | 沿用引擎画质配置；按设备和真实负载验证，不认定为设计师普适最优 |
| 东方明珠与固定城市专用资产参数 | 不纳入通用地图默认 |

相机二维／三维切换和俯仰按现有地图能力；普通透视焦距换算不能直接套在地图投影上。窗口变化时的取景保留、标签和控件布局需按[共同约定](common.md#配置与能力边界)核对，当前主题常量比较不证明响应行为通过。

## 文字、标签与业务叠加

底图行政／道路文字的颜色、描边、大小比例和密度属于原主题；`labelSize`是底图文字比例，不能当作业务卡片像素尺寸。业务标签和Vue卡片沿用[ScreenLabel](../component-docs/ScreenLabel.md)等实际能力，按项目定义数量、屏幕尺寸、缩放显隐及遮挡规则；后来的标签改动不认领为原设计师参数。

无业务数据需求时只生成底图与所需模型。散点／热力按[地图叠加层](../map-overlays.md)独立启用，保持数据单位、图例和模拟标记；这些能力的后续聚合／透明策略不属于本次主题比对。业务层不通过改写基础主题来表达数据。粒子扫光独立评估。

## 交互、加载与验收

编辑器沿用本Skill已有UI、选择、锁定、撤销及保存适配，不复制原上海页面、独立localStorage或固定城市导航。默认支持范围以[地图接入](../map.md)为准，表现覆盖与锁定归属分别处理。

地图服务可联网，按实际配置确认样式、瓦片、字体和sprite可达；离线HTML不表示地图资源离线。加载中、部分失败、不可用及重试策略按共同约定和实际宿主核对，未知行为标待验证，不以背景空白当作完整场景。

已验证：归档HTML／参数文件指纹和当前源码72项通用主题常量。未验证：真实地图效果、发布包与源码全链一致性、全部缩放／投影算法、资源异常与保存闭环、设备性能。视觉由用户确认，技术按所用功能验证。本指南不增加日常生成审美门禁。
