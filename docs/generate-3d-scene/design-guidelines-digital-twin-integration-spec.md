## 3. 设计知识与模板

设计师确认地图是地图风格依据，不推广为工厂/室内的统一配色。必须定位原始版本，不能把后来由 Agent 修改的颜色、标签阈值认领为设计师方案。

领域规则与风格分开：工厂可有明亮/深色方案，园区区分示意布局与真实地图。项目地点、数量、经纬度、绝对机位留项目；自动取景、视觉层级、缩放显隐规则可复用。

统一指南必填：来源/确认状态/适用范围、表达目标、布局与尺度、色彩及表面表现、相机浏览、配置边界、验收要点、实现对应关系。
条件必填：光照渲染、标签卡片、数据可视化、交互编辑、多主题、动画；不用的项省略。
可选：布局示例、提示词、领域特殊规则。必填规则不等于用户手填，参数来源分为模板默认、场景计算、项目提供、启用功能后提供。

还需覆盖：信息密度、遮挡、前中后景、真实/示意数据、告警语义、无数据及失败状态、可访问性、响应视口、材质/色调映射条件、不同尺度细节、加载降级和性能约束。通用技术契约引用已有说明，不在各领域复制。

文件清理计划：README 修正真实地图路由；common 保留通用原则、清理未经确认固定风格；campus 分离真实地图；warehouse/port 保留物流与尺度知识、去除被当默认的虚构数值；factory/data-center/wireless 保留领域经验、具体数量降为示例；补 geographic-map 和室内指南。实际删除前提交逐段修改清单，不整批删除有用知识。

性能：pixelRatio、抗锯齿、阴影贴图、帧率、按需渲染、LOD、纹理预算等沿用运行配置；不把设计案例数值当普适性能最优。视觉基准与设备档位分开，降低品质不能破坏业务含义。

行业参考作为知识依据而非新增强制标准：Khronos Real-Time Asset Creation Guidelines、Esri 制图原则、MapLibre Style Spec、W3C 颜色与交互动画指南。适用性逐项判断。

## 4. 面板与参数最终约定

保持现有 UI 组件、颜色、间距和操作结构。术语从双方已有名称中选，成对字段统一标准名称，不创造另一套术语。

| 项 | 决定 |
|---|---|
| 背景 | 保留“背景” |
| near/far | 显示“近裁剪面/远裁剪面”，单位一致，底层不变 |
| 旋转、自动旋转速度 | 保留“旋转”“转速”，按分组区分物体与视图 |
| 阻尼 | 可显示“阻尼”，不把其数值误解释为停止时间 |
| 画质 | 保留“画质与性能”“流畅/均衡/精细” |
| Pan | 实际入口标题待核查，不将此前功能描述冒充界面原名 |
| 焦距 | 透视主要控件“焦距 mm”，高级 FOV 只读；24 mm 固定传感器高度；fov 为存储真值 |

焦距公式：FOV_deg = 2 atan(24/(2 focalLengthMm)) ×180/π。旧工程打开只反算显示，不改变画面；正交隐藏；相机 zoom、viewOffset、地图宿主等条件须先核查，不强套换算。不直接使用不同 filmGauge 约定替代。开放传感器可调属于后续决策。

HSV、色温、网格主格为候选功能，不和改名捆绑。HSV 需确认色彩空间转换；任意颜色不反推唯一色温。角度与坐标若提供双入口，必须共享一个真实状态。

冲突待确认：对方水平/垂直 Field of View 实际方位/仰角；曝光与 lightingExposure/全局亮度；环境光与 HDR/材质反射；缩放的距离/光学/正交/地图语义；透明度与不透明度方向；场景单位切换是否改变实际尺寸。未确认时保留我们的行为。

保存/重置必须逐项说明作用于场景、对象、草稿还是模板；临时选中高亮不自动成为永久外观。不能恢复本来隐藏的物体；批量预设不能清除无关用户设置。
