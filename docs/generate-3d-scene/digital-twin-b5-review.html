本文件是可审阅设计草案，不是生成工程或运行配置。

## 1. 身份、来源与适用范围【必填】

标识：b5-factory-v1；版本：2026-11-07。普通Three可编辑去顶总览；有SMT、装配、测试、包装和线边物料资产。非真实生产工艺或消防设计，不接地图，不包含真实调度。

设计状态：布局与视觉方案是开发建议，待用户确认；用户已给定五区功能需求，不等于确认具体布局和色值。

来源索引：factory / common / types / focus / save / workflow。输入版本见[digital-twin-b5-sources.json](digital-twin-b5-sources.json)的路径与SHA-256；该清单仅审计，不是运行配置。项目需求依据本会话用户明确给出的三段prompt。维护责任：设计由用户／设计师确认，字段与能力由Skill维护开发核对。

实现状态：复用现有接口；实例尚未生成，功能和效果未验收。本版首次试填，未改变存储字段或已发布默认。

## 2. 表达目标【必填】

面向工厂布局观察与编辑：首先读出SMT→装配→测试→包装的工序关系，其次看清线边物料与主通道。设备轮廓有区别，地面标识辅助而不抢主体；设备丰富但通道可读。

## 3. 布局与尺度【必填】

单位米，+Y向上。厂房尺寸和各线数量用户未指定，由本次实例按资产占地估算并明确为示意；不继承旧项目车间数量。主通道串联五区，横向联络到各线端部，装配测试靠近相邻工序，物料架在工位侧。前景为入口与转运，中景为主要产线，后景为辅助区。顶部不遮挡内部，保留必要后墙与梁架；这是初始建模表达，不宣称动态剖切能力。AGV少量静态布置，运行调度不启用。工序间距按资产包围盒和操作空间设计，非合规净宽。

## 4. 配色与表面表现【必填】

## 5. 相机与浏览【必填】

透视斜俯视，目标为五区联合业务包围盒；剔除无限地面和辅助标记。根据宽高比计算机位，旋转缩放平移沿用Orbit。camera.position/lookAt与controls.target保持一致，near/far随范围核对。当前仍使用已有FOV配置；C3计划的24mm焦距UI尚未实现，不在本方案宣称可用。

响应视口设计：桌面横屏总览，窗口缩窄后优先保留当前观察目标和用户旋转状态；标签避免挡住主体，属性面板保持可滚动。自动重新取景、面板窄屏收起与标签避让的当前支持待开发核对，不宣称已实现；以横屏→窄窗→恢复用例确认，若现有控件无法操作则报告限制。没有已实测的最小窗口尺寸，本方案不承诺手机适配。

## 1. 身份、来源与适用范围【必填】

标识：b5-map-v1；版本：2026-11-07。真实地图服务提供OpenMapTiles兼容建筑数据，MapPresentation默认路径；其他数据源须先核对字段。建筑非Three逐栋可编辑模型，不能自动爆炸或改PBR材质。

设计状态：地图通用主题按B4确认来源；本项目取景、标签配置和实际运行未确认。

来源索引：map-guide / map-contract / presentation / theme / map-adapter / label / workflow；B4来源比较。输入版本见[digital-twin-b5-sources.json](digital-twin-b5-sources.json)的路径与SHA-256；该清单仅审计，不是运行配置。项目需求依据本会话用户明确给出的三段prompt。维护责任：设计由用户／设计师确认，字段与能力由Skill维护开发核对。

实现状态：复用现有接口；实例尚未生成，功能和效果未验收。本版首次试填，未改变存储字段或已发布默认。

## 2. 表达目标【必填】

以市民中心为关注区域，展示莲花山公园、深圳图书馆、深圳音乐厅及周边商务区。浅色清透但空间关系可辨，少量重要地点标签不遮挡地图；可切换俯视／鸟瞰和深浅主题。

## 3. 布局与尺度【必填】

WGS84地点由项目提供，center/origin及初始zoom/bearing按实际可用范围求解，本轮不猜坐标。实际建筑形状和高度来自数据源；缺失不以虚构精模冒认真实。地面道路水绿地继承地图数据。附加模型才使用米制局部坐标（X东、Y上、Z南）。主次由取景范围与少量业务标记表达，不重排真实建筑。

## 4. 配色与表面表现【必填】

| 角色 | 设计意图 | 参数来源 | 覆盖范围 | 状态 |

## 5. 相机与浏览【必填】

地图导航负责相机。map.center/zoom/pitch/bearing/view分别由实例配置；俯视／鸟瞰沿用现有地图切换。普通CameraConfig.fov与Orbit字段不驱动地图取景，不将焦距UI接到地图。初始范围包含用户指定地点，确切边界由项目实际数据核对。

响应视口设计：桌面横屏总览，窗口缩窄后优先保留当前观察目标和用户旋转状态；标签避免挡住主体，属性面板保持可滚动。自动重新取景、面板窄屏收起与标签避让的当前支持待开发核对，不宣称已实现；以横屏→窄窗→恢复用例确认，若现有控件无法操作则报告限制。没有已实测的最小窗口尺寸，本方案不承诺手机适配。

### 6.1 光照与渲染

使用当前渲染配置，不从案例抄pixelRatio、MSAA、shadowMapSize或帧率作为全设备最优。画质沿用现有档位，是否适合由后续实际设备／分辨率测试确认。场景亮度与材质可读性是设计目标，环境贴图不等于环境光、曝光不等于灯光强度。精确强度由实际场景验证，未知值由开发核对、用户确认效果。

### 6.4 交互与编辑

沿用现有模型列表、对象／场景属性、眼睛、锁、撤销重做及唯一保存入口。支持对象类型见第8节；选中反馈退出应恢复，不改永久材质。开发保存回写scene-data；离线复制修改文本不代表已写回或清除未保存状态；回传后构建验证。按workflow“编辑与回传”约定，本轮仅引用，未重跑保存闭环。重置与预设只影响声明字段集合；未声明集合前不添加一键全局重置。

### 6.2 标签与卡片

仅显示指定重要地点名称，标记用稳定ID和真实坐标；无详情卡片、无大屏。建议屏幕尺寸保持克制，缩远减少到高优先级地点，碰撞时隐藏低优先级标签，点击标签只选中对应标记。具体字号、数量上限、缩放阈值及当前组件是否完整支持此策略待开发按ScreenLabel实例核对，用户看效果后确认，不新增虚构配置字段。需关闭时沿用实际支持的显隐控制，未验证不宣称有独立关闭按钮。

### 6.5 多主题

light/dark取B4对应组件值；map.surfaces显式覆盖跨主题保留，清除覆盖回到当前主题。主题只改基础表现，业务标签和图层不被整体重置；选择、锁定及保存重载按地图适配验证。地图五类整体可编辑颜色和显隐，锁定留Skill，不提供逐栋Three材质编辑。底图文字继承主题；业务标签的深浅对比需项目确认，不能据底图主题通过推断标签效果通过。
