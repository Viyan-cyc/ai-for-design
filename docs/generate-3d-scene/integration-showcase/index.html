01 / 新增输入 + 已有能力整理

焦距与相机术语已通过

把设计师熟悉的焦距输入接到现有相机；近、远裁剪面使用成对名称。

  • 焦距 mm 与现有垂直 FOV 换算，固定传感器高度 24 mm；底层仍保存 fov。
  • FOV 在焦距旁只读显示；通常最多显示三位小数，小量参数保留必要精度。
  • 未照搬对方全部观察视角设置；正交相机和地图不强行套用焦距。
Spec §53；近远裁剪术语为原有功能命名整理。
02 / 设计能力适配

HSV 颜色输入已修复待复审

原方案在灯光中使用 HSV；我们将颜色输入做成共用控件，保持现有颜色字段。

  • 支持 HEX / HSV 切换；HSV 下只展示 H、S、V，不重复堆叠 HEX 文本。
  • 接入背景、雾、材质、灯光及地图表面等现有颜色入口；右图展示背景入口。
  • 持续取色撤销边界 P2 已修复：背景与材质跨 1.3 秒停顿仍合为一次撤销，下一次独立输入分开记录。等待独立复审。

03 / 设计能力适配

灯光色温已修复待复审

借鉴色温输入方式，近似换算为灯光颜色，不引入另一套颜色状态。

  • 不从任意颜色反推色温；图中空值是未输入色温，不是丢失颜色。与 HSV 同批待复审。
