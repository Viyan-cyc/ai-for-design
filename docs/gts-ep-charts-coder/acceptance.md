# 图表任务验收

这些任务由维护者调用新 skill 生成并在浏览器验证；静态测试不计作任务验收。当前状态：待执行（当前工具禁止 file://）。

## 任务 A：中性分类比较

请求：使用以下示例数据做可交互柱图，比较 A/B/C 三个对象的数量 12/23/18；保留原值，注明单位“件”。在宽 640px 和 420px 的容器中可读，悬停查看值，支持图片导出。不要增加业务阈值或评分。

检查：选择默认 HD 规范及柱图专项；逐项记录标题、轴、图例（如需要）、Tooltip 和颜色的实际来源；数值和单位不变；两种宽度无截断；Tooltip 正确；导出图片与当前图表一致；没有工作台/聊天/分页残留。编译、运行、视觉、交互和导出分别记录。

## 任务 B：多指标比较

请求：比较三个对象的产量、时长和缺陷数：A=(120件,30分钟,4件)，B=(95件,20分钟,2件)，C=(140件,40分钟,6件)。用平行坐标观察差异，保留单位和原值，不合成评分；支持对象筛选和数据更新。在 1024px 与 640px 宽容器中验证。

检查：根据方法路由选多对象/多指标适用方法及平行坐标专项；轴方向、单位、原值映射明确；筛选与更新后身份对应不乱；容器变化正确 resize；离开页面后销毁实例和监听。没有强行套入某个行业案例。

## 按需扩展

在同一产物上要求主题切换：EP 控件跟随主题，图表使用图表适配值；没有规范定义的暗色值明确标为建议，不宣称通过规范验收。若任务不要求主题，不加切换 UI。

## 记录格式

每个任务记录：提示词、skill/设计来源版本、产物目录、build 输出、实际查看尺寸、截图证据、实际交互、导出文件、未执行项及失败原因。结论分“静态通过”“运行通过”“视觉已核对”，不能以任一层代替其他层。
